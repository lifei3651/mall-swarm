# 灵启商城核心业务模块

`mall-distribution` 目前承载移动商城、会员关系、新零售奖金、业绩、钱包、提现、售后、运营后台及审计功能。正式业务只保留 `NEW_RETAIL_SIMPLE_DEFAULT` 一套奖金方案；旧三级分销表、旧规则节点和 V7 模拟方案不参与运行。

## 当前会员与奖金口径

- 账号注册后只是商城账号，首笔有效订单支付后才激活推广会员并进入关系树。
- 后台手工设定 1–8 级等同激活推广身份，但不会伪造订单、业绩和历史奖金。
- 等级依次为：会员、VIP会员、店铺、代理、一星董事、二星董事、三星董事、合伙人。
- 每件有效商品计 1 单；本人及全部无限层下级的有效件数均计入累计单量。
- 直推奖只发给下单人的直属邀请人，比例由直属邀请人支付时的级别决定：25%、30%、37%、45%、52%、57%、61%、65%。
- 一星董事、二星董事、三星董事、合伙人分别对无限层团队新增有效订单取得 5%、4%、3%、2% 团队分红；关系链上每位符合条件者独立取得，不做级差。
- 订单先按支付前的级别生成奖金快照，完成本单的件数与业绩累计后再升级；升级后的后续订单按新级别计奖。
- 奖金按订单确认收货时间起满 7 天进入可结算状态。
- 商品退款按实际退回件数冲减业绩、件数和对应奖金并允许降级；已发货订单的运费不参与奖金，也不在普通商品退款中退回。

## 关系与移线

- 直属邀请关系与无限层祖先关系均落库，不限制组织深度。
- 移线使用单一 `line-change:apply` 专用权限；有权限的管理员提交后立即生效，无权限的管理员在前端看不到操作入口且后端会拒绝请求。
- 每次移线仍记录操作人、原因、前后关系快照和操作日志；升级前遗留的待审批记录可由拥有移线管理权限的管理员处理。
- 被移动会员及其全部下级作为一棵完整子树移动。
- 审批时保存移动前、移动后的完整关系快照和操作日志。
- 历史订单、历史业绩、历史奖金和已经产生但尚未结算的奖金均保持原归属；只有审批生效后的新订单使用新关系。
- 移线不触发自动升降级。

## 钱包与提现

- 会员唯一资产为“余额（`CASH_BONUS`）”。奖金结算、支付、转账和提现全部使用余额。
- 余额可支付订单、按手机号转账和申请提现；转账与提现均需要独立 6 位支付密码。
- 提现还必须校验当前登录会员手机号的短信验证码，后台不能绕过会员身份代申请。
- 提现申请时立即扣减余额；审核拒绝原路退回；审核通过并线下打款后记录打款流水号。
- 所有资产增加、扣减、转账、支付和提现均有资产流水及后台操作日志。

## 商城功能

- 手机 H5 首页、搜索、分类、双列商品、购物车、结算、运费模板、地址、订单、确认收货、售后退款。
- 多主图轮播、多详情图、SKU、库存、价格、成本、PV 开关、服务保障、商品评价及后台隐藏评价。
- 微信/支付宝接口骨架已保留，但实际商户支付待商户资料和密钥后接入；余额支付可用。
- ERP 统一配置、出库任务和回调框架已保留，聚水潭/旺店通/金蝶需按客户实际账号与开放平台字段做最终映射。

## 客户配置与合规

后台“商城品牌与界面”可维护运营主体、商城名称、LOGO、主题、经营地址、客服、营业执照、ICP备案、公安备案、用户协议、隐私政策和售后政策。前台公开展示，不允许客户输入的协议正文作为 HTML 执行。

## 运维基线

- 后端只监听 `127.0.0.1:8086`，仅由 Nginx 反向代理。
- 防火墙只放行 SSH、HTTP、HTTPS；敏感接口和普通 API 分级限流。
- SSH 登录等待 30 秒、单连接最多尝试 3 次；10 分钟内连续失败 5 次会临时封禁 1 小时。密码登录暂时保留，待配置管理员公钥后再关闭。
- 每天 03:30 完整备份数据库、上传文件、配置、程序和前端，默认保留 14 天并生成 SHA-256 校验。
- 每 5 分钟检查 Java、Nginx、MySQL、Redis、HTTPS、磁盘、内存和备份新鲜度。

## 构建与测试

```bash
./mvnw -pl mall-distribution -am -DskipTests=false test
npm --prefix mall-shop-web run build
npm --prefix mall-distribution-admin run build
```

自动化测试使用 H2 和测试配置，不会访问生产数据库、短信或支付通道。生产服务器只执行只读冒烟检查，禁止使用模拟支付接口造单。

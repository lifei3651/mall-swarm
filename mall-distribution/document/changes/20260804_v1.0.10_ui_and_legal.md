**新增文件：**

**改动文件：**
- `mall-distribution/pom.xml` - 新增支付宝SDK依赖
- `mall-distribution/src/main/resources/application.yml` - 新增支付宝配置项
- `mall-shop-web/src/api/shop.js` - 新增支付宝API函数
- `mall-shop-web/src/views/CheckoutView.vue` - 结算页支持支付宝支付

**功能说明：**
- 支持电脑网站支付（收银台模式），同时兼容PC和H5
- 支付宝异步回调验签、金额校验、幂等处理
- 支持支付宝订单状态查询
- 支持支付宝退款

**配置方式：**
```yaml
alipay:
  enabled: true
  appId: your-app-id
  privateKey: your-private-key
  alipayPublicKey: alipay-public-key
  notifyUrl: https://lingqimall.com/api/pay/alipay/notify
  returnUrl: https://lingqimall.com/api/pay/alipay/return
```

应用私钥和支付宝公钥只允许通过服务器环境变量注入（`ALIPAY_PRIVATE_KEY`、`ALIPAY_PUBLIC_KEY`），不得写入代码、配置文件或日志。异步通知先验签并校验 `app_id`、金额和订单状态，仅 `TRADE_SUCCESS` 才更新订单；订单状态条件更新保证重复通知幂等。

**使用流程：**
1. 在支付宝开放平台创建应用，获取appId和密钥
2. 配置应用的异步通知地址
3. 在application.yml中配置支付宝参数
4. 用户下单时选择支付宝支付，系统自动跳转支付宝收银台
5. 支付完成后支付宝异步回调通知系统

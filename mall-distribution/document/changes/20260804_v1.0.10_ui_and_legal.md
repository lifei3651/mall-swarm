# 2026-08-04 v1.0.10 商城UI配置、协议规则与资质展示优化

## 一、已完成的修改

### 1. 商品编辑 - 售后及服务区域优化

**改动文件：** `mall-distribution-admin/src/views/shop/products.vue`

- 服务保障从6列表格布局改为标签式选择（参考淘宝/拼多多风格）
  - 预设保障以 `el-check-tag` 标签平铺展示，点击即启用/禁用
  - 鼠标悬停显示详细说明（tooltip）
  - 点击"自定义保障"按钮打开弹窗编辑详情（图标、名称、说明）
  - 整体空间节省约70%
- 售后说明从7行textarea改为折叠式编辑
  - 默认只显示一行摘要（模板名称 + 内容预览）
  - 点击展开完整编辑区域，带折叠动画
  - 整体空间节省约60%
- 新增自定义保障编辑弹窗（520px宽度）
- 移除了不再需要的 `applyGuaranteePreset` 和 `addServiceGuarantee` 函数
- `defaultServiceGuarantees` 不再限制为前5项，返回全部预设保障
- 新增图标导入：ArrowDown、Box、CircleClose、Document、Medal、Money、RefreshLeft、Star、Van

  - 新增字段 `faqs`（String，JSON格式存储常见问题）

  - 新增字段 `faqs`（String）
  - `from()` 方法新增两个字段的映射
- `mall-distribution-admin/src/views/tenant/profile.vue`
  - 营业执照上传区域新增"前台展示/前台隐藏"开关（el-switch）
  - 布局从 `align-items:center` 改为 `align-items:flex-start`
  - submit 方法新增 `showBusinessLicense` 参数
- `mall-shop-web/src/views/LegalView.vue`
  - 营业执照图片展示条件增加 `config.showBusinessLicense !== false` 判断
- `mall-distribution/document/sql/20260804_tenant_display_config.sql`（新增）
  - `dms_tenant` 表新增 `show_business_license` 和 `faqs` 字段

### 3. 协议与规则 - 默认模板 + FAQ

**改动文件：** `mall-distribution-admin/src/views/tenant/legal.vue`

- 用户服务协议：新增"填充默认模板"按钮
  - 包含总则、账号管理、商品订单、支付配送、售后、行为规范、知识产权、免责声明、争议解决等10个章节
- 隐私政策：新增"填充默认模板"按钮
  - 包含信息收集、使用、共享、保护、保存、用户权利、未成年人保护等9个章节
- 交易与售后规则：新增"填充默认模板"按钮
  - 包含交易规则、配送规则、退换货、退款、不适用情况等8个章节
- 新增常见问题（FAQ）编辑区域
  - 支持添加/删除/编辑问答
  - 内置11条默认问答，包含奖金规则详细说明
  - FAQ以JSON格式存储到 `dms_tenant.faqs` 字段
- 所有模板中的 `{company}`、`{phone}`、`{email}` 自动替换为商城资料中配置的实际值
- 填充默认模板前会弹出确认框，防止误覆盖已有内容

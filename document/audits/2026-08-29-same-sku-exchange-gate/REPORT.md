# 同规格换货闭环交付验收

日期：2026-08-29
范围：商城通用基座，本地待下一版本发布

## 产品结论

商城基座补齐“同规格换货”，但不把不同客户的制度或奖金规则写进通用商城。换货只允许原订单同一商品、同一规格、同一数量，不处理换款、补差价或退款，也不重新计算原订单资金和奖金。

采用以下通用流程：

1. 商品完整发货后，会员选择“同规格换货”并提交商品、数量、原因和凭证。
2. 商家审核通过后，会员查看退货地址并填写寄回物流。
3. 商家确认收到退件，售后进入“待发出换货商品”。
4. 商家填写替换商品物流；系统只在此时扣减一次商品和规格可售库存，不增加销量。
5. 会员确认收到替换商品后完成换货；15天未确认时系统自动完成，避免订单结算永久悬挂。

## 边界与风险控制

- 退回商品不自动回补可售库存，避免未质检商品重新出售；后续由商家线下验收后决定如何处理。
- 换货金额固定为0，不创建退款流水，不冲销业绩或奖金，不改变原订单金额与历史结算口径。
- 换货处理中会阻止该订单的奖金、平台资金和商户货款进入最终结算；换货完成后恢复原结算流程。
- 发出替换商品使用行锁、库存条件更新和事务回滚；重复提交同一物流不会二次扣库存。
- 仅已发货或已完成订单可申请换货；缺少可用退货地址时，后台不能误通过。
- 商家收到退件后默认3天补发提醒；超时只升级为平台客服优先介入，不自动发货、不自动退款。
- 不支持跨规格、换款和补差价。这类能力涉及价格、库存和客户规则，应在具体客户独立项目中定制，不进入基座。

## 实现范围

- 会员端：换货申请、处理进度、退件物流、替换商品物流、确认收货。
- 商家/平台后台：换货审核、确认退件、库存提示、发出替换商品。
- 后端：换货状态机、权限与客户隔离、幂等、库存扣减、自动确认、处理期限和操作审计。
- 数据库：新增替换商品物流公司、运单号、发出时间和确认收货时间，以及自动确认扫描索引。

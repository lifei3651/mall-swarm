# 订单取消、退款追回与会员资格组合门禁报告

日期：2026-08-28（Asia/Shanghai）

对象：App / 小程序公开商城 + 团队 H5 拆分基座（含可选一体化 H5 构建）

当前线上版本：`1.0.94`

本轮状态：线上 `1.0.94` 发布后的本地下一版本候选，未再次发版

## 一、结论

商城基座现已把“取消订单、部分退款、已结算奖金追回、首单会员资格回退”按同一笔订单的商品快照串联起来。

未支付订单只能取消，不能进入奖金和售后；支付后必须走售后退款。部分退款按实际订单商品、金额和数量冲销；已结算奖金优先从原入账钱包追回，余额不足形成可审计欠款，并由后续奖金自动抵扣。首单激活的会员只有在整单实际退完、名下没有其他有效支付订单且没有未处理资金风险时才回退资格。

## 二、发现并修复的问题

### 1. 混合订单退普通商品可能误扣团队奖金

订单允许同时包含“参与团队奖金的商品”和“普通商品”。支付时奖金基数只计算前者，但退款原先使用整笔商品退款金额和数量冲销。因此只退普通商品时，也可能错误减少团队业绩、累计件数和奖金。

现已改为：

1. 退款始终读取下单时冻结的订单商品快照，不读取商品当前设置。
2. 普通商品退款只影响订单实付、退款、商户结算和库存，不冲销团队业绩或奖金。
3. 奖金商品退款按该商品实际分摊后的金额和数量冲销。
4. 多次部分退款使用奖金商品累计退款金额计算截至本次应追回总额，避免重复追回。
5. 客户独立奖金程序收到的退款事件同时包含订单商品退款总额和奖金商品退款口径，便于派生项目重算等级、复购或其他客户资格。

### 2. 外部支付渠道未完成时可能提前回退会员资格

支付宝等外部退款采用“本地登记后、渠道使用同一售后号可恢复重试”的方式。原流程在渠道返回成功前就可能关闭整单并尝试取消首单会员资格。

现已改为：外部退款处理中保持订单和会员资格不变；只有渠道确认成功并完成本地状态恢复后，才关闭已全退订单并执行会员资格回退。渠道失败仍停留在可重试状态，不会把客户提前变成非会员。

## 三、组合流程验收矩阵

| 场景 | 订单与库存 | 业绩与奖金 | 会员资格 | 结果 |
| --- | --- | --- | --- | --- |
| 未支付单主动取消 | 仅待支付可取消，库存一次性回补 | 不产生业绩与奖金 | 不激活会员 | 通过 |
| 多商户父单取消 | 全部待支付子单与父单一起关闭，逐单回补库存 | 不产生业绩与奖金 | 不激活会员 | 通过 |
| 已发货部分退款 | 只退实际商品数量，发货运费锁定 | 精确冲销对应商品与件数 | 仍有有效订单，不回退 | 通过 |
| 混合订单退普通商品 | 正常登记退款 | 团队业绩、件数和奖金保持不变 | 保持不变 | 通过 |
| 混合订单退奖金商品 | 正常登记退款 | 只按奖金商品金额与数量冲销 | 仍有有效商品时保持不变 | 通过 |
| 已结算奖金尚有余额 | 正常完成退款 | 从原奖金钱包追回并记流水 | 依据完整资金门禁判断 | 通过 |
| 已结算奖金已经使用 | 退款不被阻断 | 未追回部分形成欠款，后续奖金自动抵扣 | 有欠款时不自动取消资格 | 通过 |
| 首单整单退款 | 整单关闭 | 业绩、件数、奖金全部冲销 | 无其他有效订单且无资金风险时回退 | 通过 |
| 支付宝退款处理中 | 保持订单未关闭，等待同售后号恢复 | 本地退款账务可审计、渠道可重试 | 不提前回退 | 通过 |

# 第十轮安全与产品链路复核报告

审查日期：2026-08-22

审查对象：商品管理、会员资产、商城前端状态与数据库迁移

审查方式：本地源码、配置、迁移计划、自动化测试和生产构建；未访问线上、未执行迁移、未修改线上数据

## 一、结论

用户提供的 38 项是候选问题，不等于 38 个已验证漏洞。本轮确认并处理 7 类真实问题：商品价格变更缺少业务审计、商品及会员状态并发覆盖、商品图片协议缺少统一约束、订单详情余额支付缺少幂等键、四个敏感表单缺少重复提交保护，以及尚未发布的操作日志迁移不能安全重试。

没有发现新的越权取款、余额流水写反、跨客户数据访问或已上线迁移冲突。当前仍采用“每客户独立部署和数据库，部署内商户按 merchant_id 隔离”，不把未来共享数据库 SaaS 的改造要求当成现网漏洞。

| 编号 | 结论 | 修复与安全不变量 |
| --- | --- | --- |

| PM04、V004 | 已加固 | 商品上下架和会员启停进入事务，先锁定目标行，再校验 0/1 状态并更新；并发管理操作不会用旧快照覆盖新状态。 |
| PM06 | 已修复 | 商品封面、图集、详情图和 SKU 图片统一只接受有主机且无用户信息的 HTTPS 地址或站内绝对路径；拒绝 `javascript:`、`data:`、HTTP、反斜杠和控制字符。正常上传返回的站内路径保持可用。 |
| F001 | 已修复 | 登录、找回密码、修改登录密码、修改支付密码在请求进行中拒绝再次提交，按钮状态与函数入口形成双层保护。 |

## 三、不按报告建议误改的项目

| 编号 | 复核结论 |
| --- | --- |
| PM01 | 平台自营商品当前只有可售/下架两个经营状态，商户商品另有完整审核状态机；接口本来就只接受 0/1，不需要套用商户审核状态。 |
| PM02 | 下架必须能够立即阻止新销售，即使已有待履约订单；历史订单使用商品快照继续发货和售后。若禁止下架，召回或违规商品反而继续成交。 |
| PM05 | `ShopSkuDTO.imageUrl` 已有 2048 字符上限，本项为误报。 |
| PM07 | LIKE 使用参数绑定，不存在 SQL 注入；允许运营搜索 `%`/`_` 不构成安全漏洞。 |
| V001 | `changeIn` 在入账后读取当前余额，并以“当前余额减本次金额”记录变更前金额；`changeOut` 同理反推变更前金额，前后值没有写反。 |
| V002、V010 | 当前每个客户独立部署、独立数据库，固定租户 1 是部署边界；部署内多商户继续由服务端会话绑定 merchant_id。未来共享数据库 SaaS 必须整体迁移，不能只改拦截器。 |
| V003 | 提现已有单笔上限、支付密码、短信验证和每分钟频率限制。每日/月度金额属于客户风控政策，客户确认额度后再配置，不能由开发任意设值。 |
| V005 | 用户转账、余额支付和提现已有幂等保护；后台人工调账要求 UUID 请求号并受数据库唯一流水约束，不存在报告描述的无防重入口。 |
| V007 | 旧会员成长值模型未进入当前等级/奖金链路，不在安全补丁中扩展死代码。 |
| V008 | 支付密码解锁已有管理员权限、确认和业务审计。 |
| V009 | 收款人无需先设置支付密码即可收款；支付密码用于其日后支出，强制收款前设置会造成合法转账失败。 |
| V011 | 会员提现从可用余额立即扣减，不会把冻结余额当成可用余额；商户资金另有独立冻结账本和提现状态机。 |
| V012 | 代理关系变更锁定整棵客户关系树，比只锁单个代理更强，保证移线和调级串行。 |
| F002 | 密码类写入结果确定，短信验证码单次消费，客户端也不会自动重放；本轮前端入口防重复已足够，不额外制造请求键生命周期问题。 |
| F004、F005 | 全局错误提示和全局遮罩属于前端架构偏好；当前页面级反馈更能避免无关请求阻塞整个商城，不作为缺陷改造。 |
| F006-F008 | 未使用方法、组件和同义 API 是清理项，不形成运行时漏洞；避免在安全修复中删除可能供后续定制使用的接口。 |
| M002 | 迁移工具已验证 12 位版本号唯一，本地 17 个迁移无重复。 |
| M003-M011 | 报告没有给出具体重复索引、错误列顺序或缺失索引的查询证据。历史迁移校验和不能随意改写；全表回填和 DDL 必须在发布备份、维护窗口与真实库计划核对后执行，不做推测性数据库重构。 |

## 四、验证结果

- 后端完整测试 393/393 通过（公共模块 8、分销模块 385），失败、错误和跳过均为 0。
- 商城测试 71/71 通过；公开商城、团队 H5、一体化 H5 三种生产构建及构建边界检查通过。
- 管理后台测试 104/104 通过，生产构建通过。
- 待发布迁移计划 17 项，版本号唯一；差异格式检查通过。

## 五、发布状态

本轮只修改本地待发布版本 `1.0.70`，没有访问或发布服务器。当前线上仍为 `1.0.62`；正式发布时必须先执行完整备份，再按迁移总账核对并执行待发布迁移。

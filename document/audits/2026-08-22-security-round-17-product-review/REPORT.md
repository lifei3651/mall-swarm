# 第十七轮安全审查复核报告

审查日期：2026-08-22

审查对象：`mall-swarm-app-h5`（App / 小程序公开商城 + 团队 H5 拆分基座，同源可选一体化 H5）

审查方式：仅核查本地代码、依赖树、构建产物、测试与部署模板；未访问线上、未执行漏洞利用、未修改线上数据。

## 结论

原报告共列出 28 项。逐项回到生产调用链后：12 项属于真实缺口并已修复，12 项属于防御性加固或遗留能力清理并已完成，4 项不构成当前漏洞且不应为满足报告形式而改动。没有发现本轮报告之外的新数据库结构问题，也没有新增数据库迁移。

本轮重点不是继续堆叠依赖，而是缩小生产运行包：`hutool-all` 改为实际使用的 `core/json/crypto`，代码生成器不再传递进运行模块，未启用的 Spring Boot Admin、Knife4j 和旧 Maven Docker 构建链被移除。日志、异常和客户私有部署模板同步收口。

## 本轮实际改动

1. 统一本地文件、ELK 参考配置和生产级别的日志脱敏与容量边界。
2. 精简生产依赖，移除未使用的监控、接口文档和旧 Docker 构建链。
3. 支付宝第三方错误、导入失败和奖金失败原因在前端响应或数据库落库前脱敏。
4. 后台 401/403 改为类型化错误码，公共异常兜底返回真实 HTTP 状态。
5. 客户私有部署模板增加数据库 TLS、四容器资源上限、MySQL/Redis/Nginx 只读根文件系统与最小权限校验。
6. 删除未被发布流程使用的旧版 `external_links` Compose 参考文件。

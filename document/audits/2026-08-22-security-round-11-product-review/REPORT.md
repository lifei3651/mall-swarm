# 第十一轮审查复核与整改报告

审查日期：2026-08-22

审查对象：App / 小程序公开商城 + 团队 H5 拆分基座

方法：只读核对报告指向的代码、状态机、事务、SQL、权限矩阵和已有测试；成立项完成本地修复与回归，未访问线上。

## 产品结论

原报告 37 条中，**14 条确认存在缺陷并已修复，6 条完成预防性加固，3 条属于已有正确设计的正面项，14 条属于误报、仅代码风格建议或当前架构下没有可利用路径**。其中最重要的真实问题不是“所有定时任务都不安全”，而是批量任务事务/异常边界过大：一笔异常不应撤销或跳过其他订单、商户和资金子任务。

## 修复后的安全不变量

1. 一笔超时订单、商户结算或移线申请失败，只影响本笔，不能撤销已成功项目或跳过后续项目。
2. 商户停业/清退与待付款订单支付竞争同一商户行锁；停业后不能产生新成交，但仍可处理历史履约。
3. 商户结算候选始终由服务端当前客户范围产生，调用方不能通过订单 ID 扩大范围。
4. 未登录使用明确错误码；格式错误、方法错误和系统异常均返回安全 HTTP 状态，不依赖文案、不泄露底层详情。
5. 实时通知失败只影响刷新速度，不影响数据库权威状态；认证/权限错误不持续重试。

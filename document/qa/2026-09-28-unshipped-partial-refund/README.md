## 规则与实现

1. 小程序和 H5 的“取消并退款”默认选中全部剩余商品，但可以逐商品调节数量，不申请的商品调为0；至少选择一件。仍使用独立类型4与异常退款接口，由商家审核。
2. 后端移除未发货必须全选的限制，沿用商品实付/优惠快照、累计退款数量和金额校验。未退商品保留，部分退款完成后订单仍可继续发货。
3. 部分取消不退运费；全部未发货剩余商品退完时沿用现有运费退还和尾差处理。已发货运费规则不变。
4. 同单申请/退款处理中继续阻止重复申请和发货，退款完成才恢复剩余商品履约。取消、拒绝、退款失败/处理中与渠道确认机制不变。
5. 后台“取消并退款”仍取消整单剩余商品，但数量改为扣除历史已退款部分，跳过已全退商品，避免重复退款或被剩余数量校验拦住。
6. 后台发货弹窗默认数量/上限同步扣除已完成退款数量；换货不算已退款商品。取消确认文案明确不重复退历史款项。

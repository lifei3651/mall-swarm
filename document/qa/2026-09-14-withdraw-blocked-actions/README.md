## 验收结论

原页面同时出现“前往支付安全”“已完成，刷新状态”“联系商城客服”三个操作。其中微信客服入口依赖微信公众平台客服能力配置，在当前商城没有可验证的有效会话；手动刷新也与页面返回时自动执行的状态检查重复。

本次移除无响应的客服入口和手动刷新按钮，只保留全宽品牌色“前往支付安全”主操作。用户从支付安全页返回后，页面 `onShow` 会自动重新读取提现条件。底部“查看提现记录”仍保留，余额、提现目标和资格说明未改。

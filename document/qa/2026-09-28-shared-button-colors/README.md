# 普通按钮配色统一（源码已验，未发布）

## 原因与范围

此前只给地址识别接入`ui-button--assist`，共用次按钮仍是灰底；首页“查看全部商品”继承旧默认。消息更多、优惠券分页等独立按钮还保留页面配色。这是接入范围遗漏，不是用户需要逐页指定。

- 小程序`secondary-button`、H5 `btn secondary`及颜色别名统一为浅主题底、主题文字/边框；`ui-button--assist`并入同一条规则。共用行内辅助按钮同步。
- 移除订单次按钮的单独白底覆盖，原紧凑尺寸和右对齐不变。
- 对两端模板扫描，将独立的查看全部商品、更多、分页、重试、重新加载及评价加载接入共用色；覆盖首页/分类、商品、消息、优惠券、地址、结算、订单、客服、内容/直播、订阅、邀请和钱包中对应的入口。购物车管理按钮同步。
- 清理消息、分页和商品页重复旧灰色声明。保留支付/确认收货等实心主操作、危险操作、禁用灰色、数量/类型选择控件、图标及纯文字入口的不同语义。不改请求、业务数据或点击处理逻辑。
- 共用门禁扫描上述普通操作文案是否接入语义类，并禁止页面用`!important`覆盖次按钮；新增漏接样本回归，防止仅靠说明文档。

## 验证

- 小程序553项、H5 188项全部通过。
- 微信工程、共用UI与业务术语检查通过；公开/团队/一体化H5构建和产物边界通过。构建存在既有大分块提示，不是失败。
- 本机隔离Chrome读取实际共用及相关页面CSS，在青绿、红、紫三组主题中验证两端普通/禁用/主操作/危险操作及订单高度，156项计算样式断言通过。小程序rpx按750设计宽等比转换，仅为CSS级验证，不冒充微信真机或完整页面验收。
- 默认Playwright浏览器未安装，改用本机已有Chrome完成上述本地检查；未安装浏览器或更改用户浏览器安全设置。

日期：2026-09-14。基线`8735e98a`，修改前远程同步一致。本轮只修改开发源码，不更新`VERSION`、固定正式小程序目录，不部署或上传。

## 头像流程

- 个人资料页移除不可控的拍照入口，改为相册单图选择后立即进入微信原生1:1裁剪；裁剪完成才上传。
- 上传成功写回当前账号资料后直接返回“我的”资料页，不再次下载预览，不显示成功确认框或成功轻提示。
- 相册或裁剪取消时安静停留；真实选择、裁剪或上传错误仍使用显眼错误提示。换号、离页和重复点击保护保持。
- 首次注册仍保留微信标准`chooseAvatar`能力，满足用户主动选择微信头像的注册需求；个人资料更换流程不再暴露独立拍照入口。

# 小程序 1.0.127 UI 优化与验收记录

日期：2026-09-06（Asia/Shanghai）。范围：用户要求优化上一轮确认的四个原生小程序问题。不是重新设计整套商城，也不是发布或完整商业验收。

## 修复内容

1. 购物车：删除按钮不再绝对定位到商品标题上方，改为独立操作行；数量按钮扩大点击区域，在既有1–99范围边界禁用；价格与数量允许换行，颜色继续跟随商城主题。
2. 商品规格：规格区域直接显示已选规格、单价及库存，复用既有`priceText`、`selectedSku`、`stock`，没有新增或修改价格计算。切换规格仍保留原有缺货保护及数量重置。
3. 商品底栏：购物车图标与文字设为不可压缩，修正按钮行高样式优先级；购物车入口固定占位，加入购物车/立即购买平分剩余宽度，不受微信原生按钮默认宽度挤压。
4. 搜索空结果：搜索无匹配、分类无商品、全商城无商品分别提示；清空搜索保留分类，查看全部清除全部筛选。展示状态跟随已提交而非尚未提交的输入，避免旧结果被草稿重新标记；保持旧响应丢弃及正确分页行为。

H5、管理后台、共享后端、网络凭据处理、会员判定、支付/退款、库存和订单规则均未修改。根版本及小程序包版本为1.0.127；其他端不升级或部署。

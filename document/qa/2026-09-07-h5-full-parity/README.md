## 新增用户问题

### 邀请返回闪动：已定位并改代码

用户本地录屏4.9秒，按0.25秒解码查看；约1.5秒为微信分享选择器，约3秒回我的页时会员徽标/邀请按钮同时消失，约4.5秒恢复。源码`profile.onHide`/`refresh`清空能力、`shareReady`控制节点有无，与症状对应。

修正：同账号保留上一屏展示，分享上下文仍立即作废；后台重新验证期间按钮留位但不可用；失败或资格取消撤销，换号/退出清旧资料。自动回归覆盖这些状态。20是最终可见态证据，不把它冒充真机分享返回全过程证明。原视频和含联系人画面的帧仅在本机临时目录分析，未提交或上传。

### 验证码后未进入：商城衔接已硬化，根因及真机仍待确认

截图是微信原生手机号核验，未用截图验证码。只读生产实际访问日志显示同一时间段已有登录请求及后续本人资料GET；仅HTTP200不能等同业务成功，也不能证明窗口停止原因。

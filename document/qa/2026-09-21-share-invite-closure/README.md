## 已确认的产品规则

1. 打开分享链本身不改变邀请关系。
2. 只有服务端判定具备邀请资格的发起账号，分享链才携带本人的八位邀请码。游客和普通购物账号仍可分享商品，但不产生邀请归属。
3. 未注册用户从分享链进入后，先核对并显示脱敏邀请人；只有在用户同意协议、授权手机号并完成首次注册时，后端才在同一事务内写入邀请人。
4. 已注册用户从他人分享链进入，只能登录或继续浏览；不新建第二账号，不改写既有邀请人。
5. 已登录账号打开他人分享时，未决邀请会被清理，不吸收为本账号关系。
6. 邀请暂存最长 24 小时；连续打开两个不同邀请时要明确选择；无效或过期邀请不会静默变成无邀请注册。
7. 邀请关系与推广/奖金资格分开：建立邀请关系不等于立即开通奖金资格，后者仍由客户已配置的加入规则决定。

## 源码证据

- `mall-mini-program/utils/share.js`：只使用当前会话从后端获得的本人邀请码，不转发本机暂存的他人邀请。
- `mall-mini-program/utils/invite.js`：解析分享参数/小程序码 `scene`，隔离 API 环境、控制 24 小时时效、处理冲突和清理会话。
- `mall-mini-program/utils/login-invitation.js` 与 `login-flow.js`：提交前核对邀请人，并只在手机号首次注册请求中带入已核对邀请码。
- `ShopAuthServiceImpl.loginOrRegisterWechat`：先按手机号查旧账号，命中即直接登录；只有不存在账号时才解析邀请人并写入新会员。

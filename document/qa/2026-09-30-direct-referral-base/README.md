# 邀请、推广资格与基础直接推荐佣金分离

日期：2026-09-30。用户确认后实施，仅后续源码和本机隔离验证，**未发版、未修改正式配置或数据**。VERSION 保持 1.0.173；本轮公网只读回读仍为 `1.0.173 / df9937c2 / 20260930-closure-1.0.173`。其他服务及微信开发版身份沿用既有发布回执，未冒称本轮重新核验。

## 本轮固定范围

| 场景 | 基座规则 |
|---|---|
| 新建商城 | 邀请关闭、佣金关闭；推广资格默认由后台明确开通。已有客户显式设置、历史演示或定制奖金程序不被自动替换 |
| 邀请开启 | 新顾客首次注册必须有有效邀请；有效购物账号可分享本人码，分享权不等于收佣资格。沿用本日已实现的注册/分享门禁 |
| 合格 A 邀请普通 B | B 购买参与商品时给 A 记直接推荐待结佣金；B 无需取得推广资格，不因计佣隐式升级 |
| 普通 B 邀请 C | 关系记录为 B；B 未取得资格就不计佣，不跳过 B 给 A 计佣 |
| 独立佣金配置 | 平台管理员设置开关、比例、首笔支付交易/持续消费与签收后等待天数；保存新不可变规则版本，保留历史版本 |
| 计佣口径 | 参与商品的实际支付商品款，不含运费和优惠券抵扣；自营商品可不参与，新商户商品仍不参与 |
| 首笔范围 | 同次购物车结算的履约子单属于同一首笔支付；未参与商品的历史支付也消耗首笔资格，退款、停用或更换规则不重置 |
| 结算 | 到达签收、售后保护期及配置等待时间且没有处理中售后后释放；后续关佣金不改变旧单结算责任 |
| 部分/全额退款 | 成功退款按参与商品及数量冲减，最后退款清除尾差；未结佣金扣待结，已结佣金按钱包/欠款账本追回 |
| 历史欠款抵扣 | 基础佣金在结算时抵扣旧债；本单后续退款可恢复原债，明确链接抵扣与恢复流水，不能把它们重复计为收入或退款 |

后台仍在原奖金配置入口，不新增业务菜单；切换历史/定制政策要求明确确认，保存需奖金配置及财务管理权限。只修必要同类入口，不扩展多级团队奖金、等级制度、商户自主计佣或客户专属政策。

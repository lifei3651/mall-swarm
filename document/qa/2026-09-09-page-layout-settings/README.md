# 页面版型配置接入与验收

日期：2026-09-09；基线：0568aaec；分支：codex/security-membership-payout。

## 本轮范围

将后台可配置版型接入实际源码，而不是再做一份静态原型。未部署、未上传、未提审，VERSION 保持 1.0.136，正式小程序固定目录不变。既有购物车闪动修复保留。

后台入口：商城设置 → 商城视觉与页面 → 进入装修工作台 → 页面版型。

| 配置 | 支持内容 |
| --- | --- |
| 共用与覆盖 | 三端共用；H5、小程序、App 分别覆盖某一页；“跟随共用”删除该页覆盖 |
| 首页 | 标准通栏、紧凑商品、分类导航、活动信息流，沿用现有结构 |
| 分类 | 商品列表、双栏目录、品类橱窗、场景导购；不再绑定首页版型 |
| 详情 | 通栏主图、留白主图；保持图片原比例及现有规格、购买、评价逻辑 |
| 品牌 | 新增可选“灵启深绿”：主色 #16734b、金额 #c43d32、白色内容区、灰色页面底；旧主题不自动更换 |
| 模块 | 开关、内容、排序仍各端共用，与页面版型分离；任一端目录版无可见模块时禁止保存 |

购物车、结算、资料等交易/账户页面本轮不提供自由装修；需要沿用已确认的统一组件规范。此处仅完成版型配置基础能力，**不是整套前后台 UI 已迁移完成**。后台手机框是布局示意预览，不是微信原生页面像素级镜像。

## 实现与兼容

- `extraConfigJson.pageLayouts` 协议版本为 1，包含 shared 与 platforms.h5/mini/app；无需新增数据库字段。
- H5 的纯函数为唯一规则源，原生小程序从既有同步脚本生成 CommonJS。App 的网页构建通过原生环境标识选择 app 覆盖。
- 无新版配置时保持旧首页与分类联动行为；仅用户保存后生成新版配置。客户端对损坏/未知配置安全回退，后台拒绝未知版本和非法选项。
- 保存保留其他扩展字段、旧兼容字段及原配置版本记录机制。未改变交易权限、限购、价格、库存、邀请、会员、奖金或支付规则。
- 新版后台配置仅对已发布新版读取代码的客户端生效；新增主题必须先部署支持它的后端。现有旧客户端不能凭远程配置获得未打包的新 UI。

## 验收结果

- 后台 176 项；H5 134 项；原生小程序 434 项回归通过。
- 后端 TenantDisplayConfigSupportTest 19 项通过：兼容、扩展保留、覆盖、非法值、未知版本、跨端目录可见性校验。
- 管理后台、公开/团队/一体化 H5、App 网页层构建通过；三种 H5 边界检查通过。保留现有构建大包警告，未生成 Android 安装包。
- 小程序同源规则一致性、工程结构检查通过；微信官方编译器 33 个 WXML、35 个 WXSS 全部通过。没有开启开发者工具服务端口。
- 独立 Chrome 临时会话运行真实本地后台与 H5，所有 API 都被模拟拦截、外网请求阻断。验收单端覆盖不串端、恢复跟随、预览切换、模拟保存后重载、未知扩展保留；1440/1280 后台行不溢出。
- H5 实际页验证小程序覆盖不影响 H5；H5 单独覆盖可切换橱窗/活动首页；375px 详情留白主图宽343px、16px两侧边距，4:3图像自然比例保持。捕获页面异常及未定义请求均为0。
- 保存测试为模拟持久化，**不是生产数据库写入验收**；微信真机、App安装包及真实业务链路本轮未实测。

## 复跑本地浏览器验收

在仓库根目录确认 `git rev-parse --show-toplevel` 后，分别启动后台与公开 H5 的 Vite 本地服务：127.0.0.1:4192（/admin/）与127.0.0.1:4193。使用安装了 Playwright 的环境执行 `node scripts/qa-page-layouts.mjs`，必要时通过 PLAYWRIGHT_MODULE 指定该模块入口。使用本机 Chrome，QA_OUTPUT 可指定结果目录，默认/private/tmp/lingqi-page-layout-qa。脚本不允许真实接口穿透。

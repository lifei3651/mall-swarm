## 问题与版本边界

- 用户真机截图显示：售后申请原因展开后为窄浮层，长原因截断、遮挡说明输入框。截图本身未证明小程序当前 Git 提交；微信平台最近有回执的开发版为 1.0.154。
- 1.0.156 虽在本机完成 C/T、封包和递归准入，但仍包含原生选择器，因此在 S/W 前标记 `SUPERSEDED_BEFORE_SW`。产品提交 `c46c165424944cad17206b634ff91b0819e0c4cd`，包 SHA-256 `ca0443d84a6856fcb04f79f9476240dfe0880e09388363a28eb99e7cf65a010b`；不得部署或上传。

## 1.0.157 修复范围

- 建立共用底部通栏选择面板，长列表滚动，取消或点遮罩保留原值，已选项可识别，禁用及非法索引不产生修改。

- 更新 `UI_ACCEPTANCE_STANDARD.md`，要求检查展开态与同类控件，避免只修截图中的单页。

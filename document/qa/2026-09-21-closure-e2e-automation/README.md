## 关键限制

1. 自动链路主要运行在隔离 H2、模拟网关和本地构建环境；它证明状态机和账务不变量，不证明外部渠道已经开通。
2. 测试日志中部分用例会故意构造“系统归集账户缺失”“外部通道失败”等失败路径；只要用例最终通过，这些日志是受测分支，不等于正式环境再次发生同类故障。
3. P0-05 仍保持未关闭。必须用同一冻结提交完成服务器部署、微信平台配置和真机真实交易，并记录订单号、金额、账号、时间、渠道回执和账本结果。
4. 本轮没有改版本号、没有部署、没有上传微信、没有创建或修改正式订单和资金数据。

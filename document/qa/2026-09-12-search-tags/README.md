# 首页搜索标签排版验收

日期：2026-09-12；基线：fb199285；分支：codex/security-membership-payout。

## 范围与规范

用户反馈小程序热门词成为宽大纵向按钮。本轮仅修改 H5/小程序首页搜索建议模板与样式，并补回归；后端、后台、交易和搜索逻辑不改。

- 标题与“清空历史”同一行，标签容器另起一行。
- 标签随词宽横排，放不下自动换行；H5 高32px/字号12px/间距8px，小程序对应64rpx/24rpx/16rpx，普通字重。
- 长词不撑开面板，显示省略号，点击/无障碍标签仍使用完整关键词。
- 原生按钮显式使用小尺寸、自动宽度与零外边距；H5 移动端隐藏提交按钮文字的选择器限制为直接子节点，避免吞掉标签文字。
- 原焦点、搜索结果、不跳分类、历史存储、清空确认及错误提示流程保留。

## 自动验证

- 小程序全量450/450，通过同源同步检查、工程检查及本次首页官方 WXML/WXSS 编译。
- H5 全量140/140，公开/团队/一体化构建及边界检查通过，保留原有大包告警。
- 新增双端标签布局与80字完整关键词点击回归；H5 同时约束两处移动端选择器，不得宽泛隐藏搜索建议文字。
- 差异空白检查通过。

## 实际浏览器验收

使用实际 HomeView 组件和内存路由，独立本机4199预览，所有请求本地模拟，只允许读请求，无生产登录、接口、客户资料或交易。

- 390×844：空历史下三个热门词全部可见，同一行各72×32px，面板高94px。
- 320×720：热门词自然排为两行，页面宽度不超过320px。
- 五个假历史词含72字长词：短词并排，长词单行省略，面板无横向溢出、按钮统一32px高。
- 点击长历史词，输入框与搜索结果保留完整72字，面板关闭，不跳分类。
- 清空输入重新显示建议；“清空历史”打开原确认框，点击取消保留历史。实际清空由既有自动回归覆盖，本轮未通过UI确认删除。
- 实测发现并修复两处移动端宽泛隐藏标签文字的样式；最终上述视觉/点击验证基于修复后的代码。
- 截图在会话中直接查看，未持久化为仓库图片。验收页签/临时服务已关闭。

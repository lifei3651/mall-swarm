## 落地范围

- 小程序/H5购物车内容标题17px、600字重、系统字体，管理按钮独立；本次不改变加减、库存、限购或既有稳定更新。
- 平台后台「商城管理 → 优惠券」，自营全部/指定商品、指定商家全部/指定商品；商家不获得发券权。平台/商家/比例分担、奖金优惠前/后、退款退券规则必须明确选定，保存及发行前确认影响，绑定配置版本。发行后只可暂停/恢复领取，不能改历史条款。
- 小程序/公开及一体化H5「我的 → 优惠券」，领券中心、已领取/已用/过期/占用状态、范围说明及可用商品查看；结算以通栏入口选券。不弹普通领取成功确认框。
- 一次结算限一张固定金额券，不与秒杀叠加。只用命中商品凑门槛和分摊优惠，运费及其他商品不参与；可用金额严格大于券额。业务及原团队奖金资格不变。
- 领取、占用、核销、取消/超时释放和按配置全子单退款退券；会员/租户隔离、请求标识、并发总量/每人上限、服务端重算均保留。已付用券订单退款按数量，现金、奖金、商家净货款按累计数量差额到分，非用券历史订单走原规则。
- H5/native退款与报价校验来自同一纯规则模块，后台退款估算引用同源规则。任何客户端金额/承担比例不能成为实际结算依据。收到明确业务拒绝可修改选券；不确定提交结果保留原请求标识并提示先核对订单。

# 商城账号与直属邀请关系收口记录

日期：2026-09-20

范围：后端、微信小程序、公开/一体化 H5 个人资料

发布状态：修复仍未发布；2026-09-21 已完成正式账号数据只读复核

## 问题与结论

1. 微信手机号快捷注册会创建真实商城会员，并把手机号作为初始登录账号。原个人资料把“尚未另设独立登录账号”错误显示为“商城账号尚未设置”，属于展示语义错误，不是账号不存在。
2. 直属邀请关系保存在会员的 `inviter_id`，原本人资料接口主动移除了该字段，页面也没有安全的邀请人摘要，因此原页面不能证明正式库中是否已绑定邀请人。
3. 普通入口注册允许没有邀请人；通过邀请入口首次注册应在同一事务中一次性绑定。既有关系不得由前端猜测、补写或自行更换。

## 本次修复

- 新增本人只读账号身份接口 `/shop/auth/account-identity`：区分手机号账号与独立登录账号，返回 `BOUND`、`NONE`、`INVALID` 三种直属邀请关系状态。
- 接口只返回邀请人的公开昵称；不返回邀请人的手机号、登录账号、邀请码或内部编号，也不执行关系写入。
- 小程序个人资料和 H5 设置页统一显示“手机号账号”，不再显示“商城账号尚未设置”；真正可选的是“独立登录账号”。
- 个人资料新增“直属邀请人”：已绑定显示公开昵称，未绑定如实显示，悬空历史关系显示“关系待核验”。
- 小程序个人中心账号摘要同步改为“手机号账号”，并扫描清理本次范围内的误导文案。

# 商城前台共用设计系统验收

日期：2026-09-20。

## 本轮范围

- 建立小程序与 H5 的同名卡片、按钮、辅助按钮、价格、状态、客服入口和操作组规范。
- 将订单列表、订单详情、首页、分类、购物车、商品详情和账户相关客服入口迁移到共用规范。
- 页面只负责布局；颜色、圆角、边框、阴影和控件高度由全局样式拥有。
- 自动门禁检查核心页面是否重新写死视觉规则，或漏用共用组件。

订单详情实际点击地址折叠项后，只显示地址，不展示姓名和手机号。视觉检查发现微信原生按钮默认尺寸会让复制、查询类按钮异常变宽，因此没有局部覆盖，而是新增全局 `ui-utility-button` 及宽文案变体后重新复拍。最终页面没有横向溢出、按钮撑破、文本遮挡或加载错误。

H5 使用本地实际源码在 390×844 和 320×800 两个视口检查，均无横向溢出、控制台错误或警告。320px 下页面宽、文档宽和视口宽均为320px，客服内容组左右边界完整，共用客服入口保持48px高；后端代理未连接，所以只验收前端骨架、共用服务入口和响应式边界，不把接口失败状态当成真实订单验收。

## 参考边界

用户提供的同行截图用于提取信息层级、留白、卡片密度和操作优先级，没有逐像素复制其品牌色或业务模块。参考图含姓名、手机号、地址和订单号，已在同轮视觉比较中查看，但未复制进仓库。

## 结论与限制

本轮验收通过的实际视觉宽度为微信模拟器约 375px，以及 H5 320px、390px。320px 发布门禁在用户恢复发版后补做完成；检查结束已恢复浏览器默认视口并关闭本地页面。设计实现阶段没有部署、上传、提审或正式发布，实际发版结果以对应版本回执为准。

# 账户表单排版修复验收

日期：2026-09-12。基线：d252c6e6；分支：codex/security-membership-payout。修改前工作区干净、pull成功，公开H5138/87dace7f、后台137/ef47181a只读一致。本轮不发布、不修改版本号及固定小程序上传工程。

## 原因与改动

- 原生支付密码页辅助入口没有显式宽度，继承微信按钮默认宽度，整句品牌色、居中后挤成两行。并且未按是否已有独立商城账号控制展示。
- 共用规则：表单沿同一左右边界排列；说明在左、短操作与箭头在右，整行点击。说明可收缩/换行，操作不拆行；品牌色只强调操作，不把普通说明当错误提醒。
- 原生两个账户页面共用 `account-security/index.wxss`：输入控件和短信按钮88rpx，验证码输入列可收缩，昵称双按钮明确均分宽度，实名长说明可换行；联系客服继续使用既有微信客服/工单入口。
- H5支付密码、登录密码、账号设置、昵称/手机弹层、实名表单共用 `src/assets/account-forms.css`：输入与短信按钮44px，短信列minmax(0,1fr)，辅助入口通栏；账号设置补常驻标签，较矮屏幕弹层可纵向滚动。
- 新账号引导仅对没有独立商城账号者展示；H5同样使用已读取的会员信息判断。点击仍进入原账号设置路径。已有支付密码仍输入原支付密码，不展示账号设置引导。
- 不改接口、密码位数/复杂度、验证码、错误锁定、实名授权、手机号双验证或会话规则；未发送真实短信、修改密码、提交身份资料或联系真实客服。不是整站UI迁移，也没有变更后台或财务规则。

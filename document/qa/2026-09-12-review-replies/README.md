# 商品评价商家 / 平台回复验收

日期：2026-09-12，执行：当前 Mac / Codex。开发基线 f32b5240，分支 codex/security-membership-payout，修改前工作区干净且 pull 成功。

## 已实现

- 后台「商城管理 → 商品评价」增加回复 / 修改回复；商家工作台开放相同入口，继续要求已有的 shop:product 权限，不自动扩大员工权限。
- 商家只可查看、回复当前商城中属于自己成交订单的评价。归属使用订单商家快照，不因商品转移给另一商家而改变；平台可回复当前商城全部评价。
- 商家、平台各保留一条公开回复，可分别修改；不替对方发言、不覆盖对方回复。原评价文字、星级、订单评价资格和评价数量不变。
- PUT /shop/admin/reviews/{id}/reply 接收 content（1～500字）、expectedVersion（新回复为0）。身份从后台会话取，不接受客户端指定商家、平台或操作者。
- 每方独立递增版本，数据库原子校验旧版本，避免不同员工覆盖新回复。相同内容重试不改变回复时间或新增业务修改日志，通用请求日志仍正常记录；页面提交锁阻止连点，失败保留草稿。
- 沿用商城配置的内容词库；回复纯文本展示，不执行HTML。不新增成功确认弹窗、短信或微信通知。
- 只有平台能隐藏 / 恢复评价。已隐藏不能新增或修改回复，顾客看不到该评价及其回复；恢复后原回复一同展示。
- 前台仅返回回复内容和时间，不返回后台操作者ID、回复版本、买家用户ID或订单信息。H5与小程序同样在原评价下紧凑展示「商家回复 / 平台回复」，无回复不留空壳。
- 操作日志保留回复前后内容（统一脱敏）、操作账号和回复身份说明。

## 本轮真实发现并修复

1. **空库结构遗漏**：换货迁移依赖 `return_received_at`，但安装允许清单漏了既有退货流程前置 SQL。增加该只读挂载，并显式按 ERP→经营地址→退货流程排序。后续真实下单又发现商品安全库存缺列；核对 86 份映射对应表后补齐新装商品/SKU 安全库存、商品限购和分类首页展示字段。新增部署后零行查询验证这些列，不再仅凭迁移计数判断结构可用。不扫描历史 SQL 目录，不修改 44 条版本化迁移。
2. **新客户默认配置错误**：历史升级为兼容旧客户默认开启邀请/多商户，空库新安装也被意外开启。仅新装基线补两个默认关闭字段，旧客户迁移、线上开关均不变。
3. **拒绝访问后其他请求偶发 500**：运营查询无权账号列表时，PageHelper 在执行 SQL 前被异常打断，分页 ThreadLocal 残留；同一 Tomcat 线程之后的登录/会话 SQL 出现双 `LIMIT`。在共用请求过滤器入口及 finally 清理，覆盖无分页参数、403、异常、空分支和坏参数，不削弱权限判断。

# 1.0.160 订单列表重复状态行收口

记录日期：2026-09-23（Asia/Shanghai）

## 用户反馈与范围

用户指出“我的订单”列表卡片顶部已有“待发货”“售后处理中”“已取消”等状态，下方独立提示行又写“商家正在准备商品”“售后进度：待审核”“订单已取消”，重复且拉高卡片。此反馈属于订单列表，不改订单详情的状态、真实物流轨迹和售后记录。

1.0.159 只做了按钮右对齐源码修复，尚未封包、留档、部署或上传微信。按代码变化分配新版本的收口规则，1.0.159 停在源码/自动测试阶段，由 1.0.160 继承按钮修复并加入本次精简；不能沿用旧版本的测试或发布回执。

## 修复与保留

- 小程序和 H5 订单列表均只在**已发货且开启自动确认收货、并无进行中售后**时显示具体自动收货时间。待支付、待发货、普通已发货、已完成、已取消及售后处理中不再为泛泛状态占一整行。
- 自动收货期限和“未收到 / 拒收”的次级入口保留；售后申请仍可通过同一卡片操作按钮进入。订单详情与售后记录不受本次精简影响。
- 新增小程序多状态数据回归、两端模板/文案回归和共用界面合同，防止泛泛状态行重新出现。

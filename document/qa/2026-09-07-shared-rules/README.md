## 防止再次分叉

`mall-mini-program/scripts/sync-h5-rules.mjs`只接受无平台依赖的命名导出模块。生成物存入`utils/h5-rules/`，文件头标明源文件，禁止手改。`npm run sync:h5-rules`更新；`npm test`与`npm run check`都先以`--check`核对实际字节，不一致直接失败。现在只是四个规则模块已建立同源，不声称所有限购、结算、账号和界面都已抽取完。

H5的OrdersView改为调用提取后的规则，请求层调用提取后的重试决策；没有修改H5页面结构、样式和用户动作。微信Token、wx.request、授权、支付、头像/地址、分享、订阅保持平台适配；不复制H5 Cookie方式或取消原有安全校验。

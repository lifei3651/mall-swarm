# 租户优惠券关闭态：本地源码与自动回归

日期：2026-09-26（Asia/Shanghai）。交付对象是可派生的测试基座，不是某客户正式商城。线上固定验证版仍为 1.0.167；本轮未封包、留档、执行正式库迁移、部署服务器、上传微信或验机。

## 改动与边界

- 新增租户 `coupon_enabled`，迁移默认值为 1，升级现有商城不静默停用；客户项目可在“商城业务模块”单独关闭。旧后台客户端未提交该字段时保留现值；普通租户资料编辑不能顺带覆盖此开关。配置版本恢复时旧快照缺字段也保留现值，真正改变开关需商城、财务及奖金配置权限。
- 服务端关闭态禁止新建草稿、重新发行、领券、结算预览选券及下单占用；无券普通订单继续走原流程。发行中的券仍可暂停。领券与下单使用同一会员→租户行锁顺序，开关更新与新领/用券串行化。
- 历史已领券、后台券列表及历史用券订单仍可查；支付后核销、待支付取消释放、全额退款退券不被开关拦截。关闭期间退回的券只作历史记录，不可再用于新订单；重开不会延长原有效期。
- 小程序、公开/一体化 H5 的个人中心、结算和直达券页根据服务端开关隐藏新领/选券入口；直达页保留历史查询。后台券页关闭后只读历史券并可暂停发行，不能新建或重新发行。页面不是安全边界，服务端门禁仍独立生效。

## 已验证

- H2 定向：关闭后领券/发行/带券报价与下单拒绝，无券订单成功；旧券历史可查，已占用订单晚到支付可核销、已支付订单退款可退券。业务模式变更权限与旧配置快照恢复也有回归。
- 后端与公共模块全量 849/849，失败 0；后台 221/221，小程序 530/530，H5 183/183，脚本合同 36/36。后端打包、后台和公开/团队/一体化 H5 生产构建、小程序工程检查、`git diff --check` 均通过。

## 尚未验证，不能放行

- 新迁移尚未在隔离 MySQL 或正式库执行；租户开关未在实际服务器和真机组合环境切换，历史订单真实支付/退款与同时切换开关的 MySQL 并发行为也未运行验证。
- 仅证明优惠券这一模块的本地关闭态，不证明余额、多商户、奖金与任意组合已可插拔。P1-15 保持待运行验收；既有 P0 和最终统一候选门禁均不因此关闭。

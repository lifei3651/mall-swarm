# 数据库版本迁移目录

这里只存放从本规则启用后新增的增量迁移，文件名必须是：

`VYYYYMMDDHHMM__lowercase_description.sql`

例如：`V202608111530__add_client_error_index.sql`。

已有的 `document/sql` 与各模块历史 SQL 视为基线，不会自动执行，防止在现有客户数据库重复建表或重复改数据。

- `V202608170900__split_public_and_team_membership.sql`：增加普通购物账号与团队业务账号的明确选择标记。历史一体化会员保持原团队资格；升级后的公开注册写入0，团队H5注册或确认关系写入1。必须在拆分版后端切换前执行并登记，禁止只发布前端。

- `V202608121715__shop_order_service_remark.sql`：增加订单客服内部备注，与客户下单留言隔离；必须随 1.0.47 程序一起发布。

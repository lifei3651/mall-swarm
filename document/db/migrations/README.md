# 数据库版本迁移目录

这里只存放从本规则启用后新增的增量迁移，文件名必须是：

`VYYYYMMDDHHMM__lowercase_description.sql`

例如：`V202608111530__add_client_error_index.sql`。

已有的 `document/sql` 与各模块历史 SQL 视为基线，不会自动执行，防止在现有客户数据库重复建表或重复改数据。

## 当前待发布迁移

- `V202608170900__split_public_and_team_membership.sql`：增加普通购物账号与团队业务账号的明确选择标记。历史一体化会员保持原团队资格；升级后的公开注册写入0，团队H5注册或确认关系写入1。必须在拆分版后端切换前执行并登记，禁止只发布前端。
- `V202608171600__multi_merchant_foundation.sql`：增加可选商户、商户货款账户、订单成本结算、提现/发票/人工打款留痕，以及商品所属商户、报单区和团队奖金模式快照。现有商品保持平台自营；发布拆分版多商户能力前必须先备份、执行并登记该迁移。
- `V202608171930__merchant_product_review_workflow.sql`：增加后台账号商户绑定、商户商品草稿/待审/通过/驳回状态，以及每次提交的销售价、结算价、SKU和商品快照。必须在多商户基座迁移之后执行；迁移完成前不能开放商户工作台账号。
- `V202608181030__merchant_settlement_cycle_and_deposit.sql`：增加商户默认及商品级结算等待天数、订单与货款等待快照、预计可结算时间、独立保证金冻结余额及幂等操作流水，并为已绑定商户账号补齐本商户货款权限。必须在前两项多商户迁移之后执行；历史待结算记录由定时任务在确认收货基础上自动补齐预计可结算时间。
- `V202608181730__merchant_security_and_finance_closure.sql`：补齐商户主体、合同、收款、开票、保证金目标和资料版本，给提现申请增加持久请求号及收款资料快照，并把发退货地址划分为平台私有、平台共享和商户私有。必须在前三项多商户迁移之后执行；执行后先由平台完善商户资料和保证金，再开放商户商品审核与提现。
- `V202608181930__merchant_controls_ledger_and_workbench.sql`：把商户账号、经营、履约、提现、结算、保证金、审核和退出状态拆开，新增商户资金总账与提现审批轨迹。必须在前述多商户迁移之后执行；旧“停用”商户迁移为“暂停新交易但保留登录和历史履约”，避免遗留订单无人处理。
- `V202608182130__merchant_exit_withdrawal_reconciliation.sql`：增加提现风控冻结前状态、商户资金总账业务唯一索引，并为尚无流水的旧商户账户写入期初余额。必须在 `V202608181930` 之后执行；若历史总账已存在相同业务键，迁移会拒绝创建唯一索引，应先备份并人工核对重复来源，禁止直接删除流水绕过。
- `V202608182245__multi_merchant_parent_trade.sql`：增加跨商户一次结算的交易父单，并给现有商城订单增加父交易、联合支付单号和支付渠道单号。执行后用户可一次支付多个商户商品，各商户继续按独立子订单发货、售后、退款和结算；发布该程序前必须先备份、执行并登记迁移，禁止只替换前端。
- `V202608211430__late_payment_refund_marker.sql`：给交易父单与历史单订单增加“超时关单后的迟到支付已原路退款”幂等标记。支付宝退款成功后必须先保存该标记再向渠道确认成功，重复异步通知和同步补单只确认既有结果，不重复发起退款。
- `V202608211700__commission_finance_tenant_isolation.sql`：给佣金追回、结算批次和结算明细增加客户租户字段及组合索引；历史单客户数据归入默认租户1，程序切换后全部读写以认证会话绑定的当前租户为准。必须在 1.0.64 后端切换前备份、执行并登记，禁止只替换程序不迁移表结构。
- `V202608211730__performance_ranking_indexes.sql`：为业绩排行榜的有效业绩时间聚合及有效上下级关系聚合增加组合索引；不修改业务数据，必须在 1.0.66 程序切换前通过迁移总账幂等执行。

- `V202608121235__tenant_after_sale_window.sql`：为商城客户增加售后期限起算模式与有效天数；默认“签收后 7 天”，可切换为兼容的“下单后起算”。发布前须先核对迁移登记和线上实际字段，禁止凭日志猜测或重复执行。
- `V202608121635__flash_sale_and_repurchase_foundation.sql`：增加默认关闭的秒杀与复购业务模式、商品复购价格/PV/限购、订单业务类型及秒杀活动/资格表。必须随 1.0.47 程序一起发布，迁移成功前不得替换后端。
- `V202608121715__shop_order_service_remark.sql`：增加订单客服内部备注，与客户下单留言隔离；必须随 1.0.47 程序一起发布。

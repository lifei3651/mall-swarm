# 商城协议模板使用说明

本目录中的文案是商城基座的通用初稿，不应直接以未填写状态发布。每个客户上线前，应由该商城的实际经营主体补齐方括号中的信息，并结合商品类型、支付渠道、售后政策、会员推广方案和所在地实际情况进行复核。

## 上线前必须补齐

- 商城运营主体全称、统一社会信用代码、经营地址。
- 客服电话、客服邮箱、工作时间、投诉与争议处理渠道。
- 协议版本号、生效日期、更新日期。
- 实际使用的短信、支付、地图、物流、云服务和统计服务提供方及其隐私政策链接。
- 各类个人信息的保存期限或明确的期限判断标准。
- 注销账号、撤回同意、查询、更正、复制、删除个人信息的实际入口。
- 商品不适用七日无理由退货的具体情形，以及退换货地址、时限和运费承担规则。

## 页面与系统要求

1. 注册页只强制勾选《用户服务协议》和《隐私政策》，不得默认勾选。
2. 《交易与售后规则》在商品详情、确认订单和个人中心保持可查看。
3. 《会员推广与奖励规则确认书》只在用户主动申请或满足条件进入推广/奖励体系前单独展示、单独勾选，不与普通商城注册捆绑。
4. 营销短信、读取通讯录、精确定位、身份证/银行卡等非基础注册所必需的权限，应按实际场景另行告知并取得相应同意。
5. 后端应保存协议类型、协议版本、同意时间、用户编号、来源终端和必要的审计信息；只在前端保存一个勾选状态不能形成完整的同意记录。
6. 长沙灵启软件开发有限公司只作为软件开发、部署实施和技术维护服务方展示。商品经营、交易履约、售后及用户运营责任由实际商城运营主体承担。

> 说明：本模板用于产品和技术落地，不替代律师结合经营资质、商品品类和业务模式出具的正式法律意见。

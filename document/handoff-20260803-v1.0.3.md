## 新对话可使用的三个插件

用户刚安装：Codex Security、Product Design、Sentry。新对话应按任务需要使用，并在使用前读取对应技能说明。

建议顺序：

1. **Codex Security**：对当前实际商城代码做标准安全扫描，重点检查敏感字段传输、后台认证、会话、防重放、余额写入、支付幂等、越权和服务器暴露；不要根据旧版 mall-swarm 默认功能下结论。
2. **Product Design**：按用户要求从后台“工作台”开始，沿业务流程逐页审查，不做脱离现有业务的泛化重设计；先给出证据和优先级，再修改。
3. **Sentry**：先只读确认项目是否已配置 Sentry；如未配置，给出适合 Java 后端、Vue 商城和 Vue 后台的接入方案，未经用户同意不要向外部服务上传生产数据或密钥。

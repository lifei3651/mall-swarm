# API 错误码与前端处理说明

## 1. 通用响应码

| 响应体 code | 含义 | 常见场景 | 前端处理 |
| ---: | --- | --- | --- |
| 200 | 成功 | 查询或写入完成 | 使用 `data` 更新页面 |
| 400 | 参数校验失败 | 必填项为空、格式错误、长度超限、数值越界 | 提示服务端 `message`，定位到对应字段 |
| 401 | 未登录或会话过期 | Cookie/Token 无效、账号在另一设备重新登录 | 清理页面会话并跳转登录页 |
| 403 | 无权限 | 管理员缺少权限、请求来源校验失败 | 提示无权限，不自动重试 |
| 429 | 请求过于频繁 | 登录、短信或写接口触发限流 | 短提示并按 `Retry-After` 或页面倒计时后重试 |
| 500 | 业务处理失败或系统异常 | 库存不足、状态冲突、支付失败；未知异常统一脱敏 | 展示准确 `message`；不得展示堆栈、SQL 或内部路径 |

接口可能使用 HTTP 200 承载业务响应体，调用方必须同时判断 HTTP 状态和响应体 `code`。文件下载和第三方回调不使用该 JSON 结构。

## 2. 常见业务提示

当前项目没有伪造一套未在代码中落地的数字子码；稳定识别依据是通用 `code`，用户可读原因由 `message` 给出。

| 业务分类 | 典型 message | 页面动作 |
| --- | --- | --- |
| 登录 | `请先登录`、`账号或密码错误`、`账号已锁定` | 登录弹窗或跳转登录；锁定时显示恢复方式 |
| 短信 | `短信验证码错误`、`请求过于频繁` | 定位验证码框或展示 1～2 秒短提示 |
| 商品 | `库存不足，最多可购买X件`、`商品已下架` | 阻止加购/结算并刷新商品数据 |
| 订单 | `订单正在提交，请勿重复操作`、`订单状态不允许当前操作` | 禁用重复操作并重新获取订单状态 |
| 支付 | `支付密码错误`、`支付密码已锁定`、`余额不足` | 保留订单，关闭或停留在支付面板并准确提示 |
| 资金 | `转账正在处理，请勿重复操作`、`提现申请正在处理，请勿重复操作` | 查询流水/提现记录后再允许新操作 |
| 售后 | `可退数量不足`、`售后状态不允许当前操作` | 刷新售后详情，不重复提交 |
| 权限 | `没有相关权限` | 隐藏无权入口并记录审计信息 |
| 系统 | `系统内部错误，请稍后重试` | 保留用户输入，允许稍后重试并由日志追踪 |

## 3. 参数校验和安全输出

- 对账号、手机号、验证码、密码、商品、SKU、公告、轮播、地址、物流、退款、评价、租户和 ERP 回调等写入字段设置必填、长度、格式或数值范围。
- 普通文本不做“一刀切”的特殊字符删除；地址、名称等合法中文标点必须保留。账号、手机号、验证码等结构化字段使用白名单格式。
- SQL 参数使用 MyBatis `#{}` 绑定，禁止把用户输入拼接到 SQL 结构中。
- Vue 普通插值默认转义；禁止把用户可控内容传入 `v-html`、`innerHTML` 或脚本执行接口。支付宝支付页仅允许重建官方 HTTPS 网关的隐藏字段表单。
- 富文本若后续开放，必须单独引入标签/属性白名单清洗，不能沿用普通文本策略。

## 4. 维护规则

新增稳定的业务数字码时，应先写入代码枚举和自动化测试，再更新本文件；禁止文档先声明、代码却仍返回其他值。错误提示必须面向客户准确表达，同时在服务端日志中使用关联编号定位，不得把敏感信息放入响应。

# 灵奇商城安卓更新说明

## 用户是否需要重新安装

- 只更新后端接口、数据库规则、商品、订单、奖金或管理后台：用户不需要重新安装安卓APP。
- 修改商城APP内置的前端页面：当前版本需要生成新APK。APP启动时会读取线上版本清单，发现更高版本后提示用户下载并覆盖安装。
- 修改安卓原生权限、系统插件、应用图标或启动配置：必须生成新APK。
- 直接下载的APK不能绕过安卓系统静默安装；正式上架应用市场后，是否自动更新由用户手机的应用市场设置决定。

## 版本发布约束

1. 每次APK版本必须同时递增 `versionCode` 和 `versionName`。
2. 构建完成后计算APK的 SHA-256，写入 `mall-shop-web/public/downloads/android-release.json`。
3. 下载地址必须使用 HTTPS，APK文件名、版本清单和实际版本保持一致。
4. 发布时先上传APK，再发布指向该APK的版本清单，防止用户收到更新提示后下载404。
5. 回滚时先恢复版本清单；已安装的新版本不能通过降低 `versionCode` 自动降级。
6. 应用市场正式版必须改用正式签名，测试用 debug 签名包不能作为正式上架包。

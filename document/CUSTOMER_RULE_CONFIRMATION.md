# 客户规则确认表（奖金结算基础约束）

> 用途：在客户提供具体奖金制度前，先确认所有奖励都必须遵守的结算、退款、风控和账务约束。
>
> 本表不定义直推奖、双轨奖、复购奖、董事奖、区域奖、包裹奖等具体奖金模型，也不固定比例、层级或会员等级。奖金模型后续按客户方案重新设计，本表只约束基础处理流程。

## 二、基础约束确认

### 3. 邀请关系与推广资格

| 确认项 | 可选方案 | 客户确认 |
| --- | --- | --- |
| 邀请关系 | 扫码注册时一次性直接绑定；已有账号在团队端首次绑定 |  |
| 推广资格开通 | 关闭 / 受邀即开通 / 后台审核 / 历史首笔有效订单兼容 |  |
| 后台审核资料 | 不需要 / 实名 / 协议 / 客户指定资料 |  |
| 资格取消与恢复 | 后台人工 / 客户制度自动事件 / 客户自定义 |  |

**必须明确：**邀请关系只证明“谁邀请了谁”，不等于已经进入客户奖金制度。新客户在制度开发和验收完成前保持关闭；不得把购买、复购或任一客户的资格条件写成所有商城的固定规则。

### 4. 奖励冻结与释放

| 确认项 | 可选方案 | 客户确认 |
| --- | --- | --- |
| 奖励产生时点 | 支付成功 / 发货 / 收货 / 订单完成 / 客户自定义事件 |  |
| 奖励状态 | 待结算 → 已结算；待结算期间不可提现 |  |
| 冷却期 | 无 / 固定天数 / 客户自定义 |  |
| 释放条件 | 订单完成且无售后 / 冷却期结束 / 客户自定义 |  |
| 订单关闭 | 奖励不产生 / 待结算奖励取消 / 按客户规则处理 |  |

**必须明确：**奖励何时生成、何时可见、何时可提现，不能只写“下单后到账”。

### 5. 提现次数与累计金额

| 确认项 | 基座默认值 | 客户确认 |
| --- | --- | --- |
| 每日最多申请次数 | 5 次 |  |
| 每月最多申请次数 | 50 次 |  |
| 每日累计金额上限 | 100,000 元 |  |
| 每月累计金额上限 | 1,000,000 元 |  |
| 审核拒绝后的处理 | 仍计申请次数，退回金额不再占累计金额 |  |

**必须明确：**四项限制由后端按同一会员串行校验，客户确认后可以配置，不能只依赖团队 H5 提示或接口限流。

### 6. 退款、取消和关闭订单

| 场景 | 默认建议 | 客户确认 |
| --- | --- | --- |
| 支付后未发货退款 | 未释放奖励直接取消；已产生待结算记录则冲正 |  |
| 发货后退款 | 先冻结相关奖励，售后结论确定后再释放或冲正 |  |
| 收货后退款 | 按退款金额和受影响商品重新计算应保留奖励 |  |
| 订单取消 | 未结算奖励取消；已结算奖励进入追回流程 |  |
| 售后拒绝 | 恢复原结算状态，不重复生成奖励 |  |
| 重复退款通知 | 依据退款单号幂等处理，不重复扣减 |  |

### 7. 奖励已提现后发生退款

| 确认项 | 可选方案 | 客户确认 |
| --- | --- | --- |
| 已提现奖励追回方式 | 余额扣回 / 后续奖励抵扣 / 形成待收款 / 客户自定义 |  |
| 余额不足 | 允许负余额 / 冻结未来奖励 / 转人工审核 / 客户自定义 |  |
| 追回通知 | 自动通知会员 / 后台人工通知 / 两者同时执行 |  |
| 追回期限 | 即时 / 下个结算周期 / 客户自定义 |  |
| 会员注销或封禁 | 保留待收账务，不得因账号不可登录而删除流水 |  |

**必须明确：**已提现不等于平台无法追回，必须确定追回凭证、金额和后续处理人。

### 8. 部分退款、多次退款和组合商品

| 场景 | 默认建议 | 客户确认 |
| --- | --- | --- |
| 部分商品退款 | 只回滚退款商品对应的奖励，不影响其他商品 |  |
| 部分金额退款 | 按退款金额占比回滚；如客户有固定奖励，按客户方案确认 |  |
| 多次退款 | 每张退款单独生成冲正记录，累计不得超过原奖励 |  |
| 组合商品退款 | 按子商品或组合规则拆分奖励基数 |  |
| 运费退款 | 默认不计入奖励基数，除非客户明确要求 |  |
| 优惠券/余额支付 | 明确奖励基数按商品原价、折后价还是实付金额计算 |  |

### 9. 封顶、利润和风险控制

| 风控项 | 是否启用 | 参数/说明 |
| --- | --- | --- |
| 奖金拨出率上限 |  | 订单或周期维度 |
| 利润率下限 |  | 低于阈值时禁止结算或转人工审核 |
| 亏损订单数上限 |  | 日 / 周 / 月维度 |
| 单会员奖励上限 |  | 单笔 / 单日 / 单月 |
| 团队奖励上限 |  | 团队或区域维度 |
| 异常订单冻结 |  | 高频下单、同设备、多账号、异常地址等 |
| 风控处理方式 |  | 自动拦截 / 延迟结算 / 人工审核 |
| 风控解除人 |  | 管理员角色和复核要求 |

**必须明确：**触发风控后是“不产生奖励”、 “暂不释放”，还是“进入人工审核”，三者不能混用。

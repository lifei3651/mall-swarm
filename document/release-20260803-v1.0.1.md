# 灵启商城 1.0.1 发版报告

发布时间：2026-08-03 12:49～12:55（Asia/Shanghai）  
发布结果：成功  
线上版本标记：`/opt/lingqimall/VERSION = 1.0.1`

## 本版已更新

### 商城前端

1. 注册页明确标记邀请码、手机号、用户名、短信验证码、登录密码和协议勾选为必填项；昵称明确为选填。
2. 提交时按字段显示友好错误并定位到首个错误项，不再只给笼统提示。
3. 中国大陆手机号统一执行 `1[3-9]` 开头的11位格式校验；输入自动过滤非数字并限制11位，短信登录和忘记密码同步采用同一规则。
4. 手机号格式正确时明确提示仍需短信验证码确认号码真实可用。
5. 用户名调整为注册必填，长度2～64字符；登录密码限制6～32位；昵称最多64字符。
6. 从注册页进入用户协议、隐私政策或售后规则后，点击返回可回到原注册页，并保留本次页面生命周期内的表单内容；密码和验证码不写入浏览器持久存储。
7. 购物车商品名称改为最多两行展示，商品图使用更合适的裁切和放大方式，件数按商品总数量计算。
8. 购物车管理模式增加“清空”及二次确认，明确提示清空不可撤销。
9. “我的”页面按移动端视口撑满，退出区域靠近底部导航，修复大块空白区域。

### 后端

1. 后端同步强制校验用户名必填及2～64字符，避免绕过前端提交不完整账号。
2. 后端同步限制登录密码6～32位、昵称最多64字符。
3. 保留并重新验证敏感请求字段加密、未加密载荷拒绝、HTTPS、会话和端口收口安全基线。

### 管理后台

本版没有新增管理后台业务功能；为保证三端来源一致，管理后台仍从当前源代码重新构建、校验并同步发布。

# 客户项目模块选择与放行门禁

> 2026-09-26 初版。适用于从通用商城基座派生的独立客户项目；当前基座测试站不是任何客户的正式商城。本文是选型与验收合同，**不是已实现任意模块即插即用的证明**。当前缺口及源码证据见 `../qa/2026-09-26-base-module-boundary-audit/README.md`，全局优先级见 `../MALL_CLOSURE_LEDGER.md`。

## 每个客户先冻结选择，不按页面开关猜模块

客户项目在开发前记录：来源基座提交、公开商城/小程序/团队 H5 的选择、支付渠道、余额、奖金/团队、营销、商户模式、物流、客服/短信和外部 ERP；每项填 `启用`、`不启用` 或 `待客户确认`，并写明负责人、依赖与验收用例。没有可核对的选择记录，不得生成“已按需组装”的交付结论。

| 能力 | 当前边界 | 客户项目选择规则 |
|---|---|---|
| 账号与权限、商品库存、购物车、订单、支付/退款安全抽象、履约售后、审计 | 交易内核 | 不按运营模块裁剪；所有客户项目均验状态机与账务守恒 |
| 微信/支付宝支付渠道 | 已有独立配置和接口；客户交付预检允许至少一条配置完整，**不代表真实联通** | 选择实际渠道；未选渠道必须保持关闭且不能被客户端误调用，所选渠道须用客户凭据完成支付、回调、退款和对账 |
| 余额 | 已嵌入结算/资金链路，尚无独立关闭态组合证明 | 不能只隐藏“余额”按钮就宣称移除；若不选，先完成接口、订单、退款与资金的关闭态测试 |
| 团队 H5、推广与奖金 | 客户派生默认奖金程序为 `CUSTOMER_BONUS_DISABLED`；私有部署已增加仅公开商城的本地构建/预检路径，未做真实容器部署与后置验收 | 不选团队 H5 时使用配对的 `--without-team-h5` 构建与配置并在客户隔离环境验静态资源/域名/回滚；不选奖金时另验零奖金与无越权入口。站点不交付**不等于**奖金后端模块移除；客户奖金制度只在独立项目实现 |
| 秒杀、复购区 | 有租户开关和顾客交易门禁；秒杀后台新建/启用关闭态已补本地 C/T，历史订单退款回补不受开关阻断 | 仅视为部分关闭能力；还须验隔离 MySQL 并发、菜单、直达 API、定时任务、历史订单与奖金/退款组合，见 `../qa/2026-09-26-flash-sale-closed-mode/README.md` |
| 优惠券 | 已补租户总开关和小程序/H5/后台、服务端新领券/新用券关闭态；仅本地 C/T，新迁移与历史退款仍缺运行验收 | 当前**不能承诺已独立交付**；客户不选时须在其隔离环境验证关闭态、旧券追溯和退款逆流程，见 `../qa/2026-09-26-tenant-coupon-closure/README.md` |
| 多商户 | 与订单、商品归属和结算耦合 | 尚未证明可降为单商户包；先明确客户是否只是“一家商户运行”，不能声称代码模块已剥离 |
| ERP | 已配置启停；本轮补上旧任务执行前门禁和自动队列过滤 | 未选或停用时不得继续外推订单/接受回传；选用具体厂商须单独完成授权、字段、签名与回传联调 |
| 微信物流、短信、实名、自动打款等外部服务 | 各自存在配置或代码边界，部分依赖平台开通与供应商凭据 | 逐项取得提供方实际回执；模拟状态机、配置保存或页面存在都不等于已开通 |
| 首页运营块、主题、版型、底部导航 | 装修层开关与排版配置 | 可以作为展示选择，但隐藏入口不等于关闭交易接口或后台任务 |

## 逐模块放行记录

每个选中/未选中模块都要在客户项目留一行以下记录，并保存证据链接：

`模块｜选择｜默认值｜页面/权限｜API/服务端门禁｜任务/回调｜数据与迁移｜对支付/退款/订单的依赖｜自动测试｜运行验收｜第三方回执｜结论`。

- **启用态**：从页面到 API、任务与账务走完整路径；权限角色和异常/重试/幂等均覆盖。
- **关闭态**：按钮与直达地址不可误用；API 明确拒绝或安全降级；已有待处理任务不得继续向外发消息/款项/订单；保留历史记录、退款和追溯能力，不清库。
- **组合态**：至少覆盖所选支付渠道 × 订单/退款、奖金关闭 × 订单/退款、营销关闭 × 普通下单、ERP关闭 × 旧待推任务；具体客户组合另补矩阵。
- **证据层级**：代码/自动测试、服务器部署、微信平台、真机运行、第三方回执分别记录。任一缺失不得用“模块已交付”笼统代替。

当前阻断项以总账 P0/P1 为准；本文件不授权自动发布、写客户生产库或接入真实资金。

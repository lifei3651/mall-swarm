# 灵启商城《用户操作手册》

适用版本：`1.0.69 app-h5-split`（本地候选，尚未发布）

适用对象：商城会员、客服、商品运营、订单运营、财务人员、商城管理员

说明：客户可选择“公开商城 + 团队 H5”拆分入口，也可选择“一体化 H5”单入口。拆分入口中，公开商城只用于购物、订单和售后，团队功能在团队 H5 操作；一体化入口中，两类功能都从同一商城进入。

### 选择客户提供的入口

1. 客户提供两个网址时，打开公开商城进行购物，打开团队 H5 处理邀请、业绩、钱包、转账和提现。
2. 客户只提供一个一体化 H5 网址时，从该网址完成注册、购物、订单、售后和团队业务。
3. 一体化 H5 登录后，点击“我的”进入完整个人中心。
4. 在个人中心点击“邀请”“余额”或“业绩”，进入对应团队功能。
5. 商城启用复购区时，在首页点击“会员复购”；未启用时不显示该入口。

## 一、公开商城会员端

### 1. 浏览首页

1. 打开商城首页。
2. 向下浏览轮播图、快捷入口、推荐分类、推荐商品、服务保障和商城公告。
3. 点击轮播图或快捷入口，进入对应活动、分类或商品页面。
4. 点击商品卡片，进入商品详情。
5. 页面加载失败时，点击“重新加载”。

### 2. 按分类查找商品

1. 点击底部“分类”。
2. 在左侧选择商品分类。
3. 在搜索框输入商品名称或关键词。
4. 点击目标商品，进入商品详情。
5. 需要直接加入购物车时，点击商品卡片上的购物车按钮。

### 3. 搜索商品

1. 在首页或分类页点击搜索框。
2. 输入商品名称或关键词。
3. 点击“搜索”。
4. 在结果中选择商品。
5. 没有结果时，修改关键词或切换分类后重新搜索。

### 4. 查看商品详情

1. 点击商品进入详情页。
2. 查看商品图片、售价、可得积分或业绩值、库存、限购、运费和服务说明。
3. 有多个规格时，点击“选择规格”。
4. 选择所需规格和数量。
5. 向下查看商品介绍、评价和售后服务说明。
6. 点击“加入购物车”继续选购，或点击“立即购买”进入结算。

### 5. 注册账号

1. 点击“登录/注册”。
2. 切换到“注册”。
3. 输入手机号。
4. 输入登录账号；账号须以英文字母开头，使用字母、数字或下划线。
5. 输入登录密码。
6. 点击“获取验证码”，填写手机收到的短信验证码。
7. 阅读《用户服务协议》和《隐私政策》。
8. 勾选同意协议。
9. 点击“注册并登录”。
10. 注册成功后进入普通商城个人中心；公开注册不会自动建立团队关系。

### 6. 登录账号

#### 密码登录

1. 进入登录页。
2. 选择“密码登录”。
3. 输入手机号或登录账号。
4. 输入登录密码。
5. 输入图形验证码；看不清时点击验证码刷新。
6. 点击“登录”。

#### 短信登录

1. 进入登录页。
2. 选择“短信登录”。
3. 输入手机号。
4. 点击“获取验证码”。
5. 输入短信验证码。
6. 点击“登录”。

### 7. 找回登录密码

1. 在登录页点击“忘记密码”。
2. 输入绑定手机号。
3. 点击“获取验证码”。
4. 输入短信验证码。
5. 输入并确认新密码。
6. 点击“重置密码”。
7. 返回登录页，使用新密码登录。

### 8. 加入购物车

1. 在商品详情选择规格和数量。
2. 点击“加入购物车”。
3. 点击底部“购物车”。
4. 勾选需要结算的商品。
5. 点击“+”或“-”调整数量。
6. 删除商品时，点击删除并在确认窗口中再次确认。
7. 点击“去结算”。

### 9. 立即购买

1. 打开商品详情。
2. 选择规格和数量。
3. 点击“立即购买”。
4. 进入结算页后核对商品；此次购买不会合并购物车中的其他商品。

### 10. 新增或选择收货地址

1. 在结算页点击收货地址区域，或进入“我的 → 收货地址”。
2. 点击“新增地址”。
3. 填写收货人、手机号、省、市、区/县和详细地址。
4. 需要时开启“设为默认地址”。
5. 点击“保存”。
6. 返回地址列表，点击“使用此地址”。
7. 修改地址时点击“编辑”，修改后点击“保存”。
8. 删除地址时点击“删除”，确认无误后再次点击“删除”。

### 11. 提交普通订单

1. 从购物车或“立即购买”进入结算页。
2. 选择收货地址。
3. 核对商品、规格、数量、商品金额、运费和应付金额。
4. 购物车含多个商户时，按商户核对商品和各自运费；页面会提示“联合结算”，但只需提交和支付一次。
5. 在“订单备注”中填写需要商家注意的内容；没有备注可留空。
6. 选择页面提供的支付方式。
7. 点击“提交订单”。
8. 页面提示大额支付验证时，获取并填写短信验证码。
9. 提交后进入付款或订单详情页面。

### 12. 支付订单

#### 余额支付

1. 在结算页选择“余额支付”。
2. 未设置支付密码时，按提示先完成支付密码设置。
3. 输入六位支付密码。
4. 点击“确认支付”。
5. 等待页面显示支付结果，不要重复点击。
6. 多商户联合结算时，一次余额扣款会同时支付全部商户子订单，不需要逐单重复付款。

#### 支付宝支付

1. 在结算页选择“支付宝”。
2. 点击“确认支付”。
3. 按页面提示跳转到支付宝完成付款。
4. 返回商城后等待订单状态更新。
5. 未跳转、付款中断或状态未更新时，进入“我的 → 待付款”，打开原订单并点击“立即支付”，不要重新从购物车下单。
6. 多商户联合结算时，支付宝账单对应一个联合支付单号，各商户订单仍分别发货和售后。

### 13. 查看订单

1. 点击“我的”。
2. 点击“全部订单”，或点击待付款、待发货、待收货、售后等快捷入口。
3. 按订单状态筛选。
4. 点击订单卡片进入订单详情。
5. 查看订单号、下单时间、支付信息、收货地址、商品、金额、买家备注和物流信息。
6. 看到“联合支付”标识时，当前卡片是一张商户子订单；同一联合支付下的不同商户会分别展示和履约。

### 14. 取消待付款订单

1. 进入“我的 → 订单”。
2. 找到“待付款”订单。
3. 点击“取消订单”。
4. 联合支付订单尚未付款时，取消任一子订单会同时取消该次结算下的全部子订单并释放全部库存。
5. 在确认窗口核对订单。
6. 点击“确认取消”。

### 15. 确认收货

1. 进入“我的 → 订单”。
2. 找到“已发货”订单。
3. 确认商品已经收到且数量、外观无误。
4. 点击“确认收货”。
5. 在确认窗口再次点击“确认收货”。

### 16. 查看物流

1. 进入订单详情。
2. 查看物流公司、物流单号和发货时间。
3. 系统已经接入物流轨迹时，继续查看运输节点和更新时间。
4. 页面只显示物流公司和单号时，复制物流单号到承运商官方渠道查询。

### 17. 申请售后

1. 进入订单详情。
2. 点击“申请售后”。
3. 选择“仅退款”或“退货退款”。
4. 勾选需要售后的商品。
5. 设置每件商品的退回数量。
6. 选择或填写售后原因。
7. 有破损、错发或质量问题时，点击“添加图片”上传凭证；最多 6 张，单张不超过 5MB。
8. 核对系统计算的退款金额和已上传凭证。
9. 点击“提交申请”。
10. 返回订单详情查看审核状态和凭证。

### 18. 取消售后申请

1. 进入订单详情。
2. 找到仍在等待处理的售后申请。
3. 点击“取消申请”。
4. 在确认窗口点击“确认取消”。

### 19. 填写退货物流

1. 等待商家同意退货退款申请。
2. 按商家提供的退货地址寄回商品。
3. 进入订单详情，找到对应售后单。
4. 点击“填写退货物流”。
5. 填写物流公司和物流单号。
6. 核对无误后点击“提交”。
7. 保留寄件凭证，等待商家确认收货和退款。

### 20. 发表商品评价

1. 在已确认收货的订单中进入商品详情或评价入口。
2. 选择一至五星评分。
3. 填写评价内容。
4. 点击“提交评价”。
5. 提交后在商品评价区域查看展示状态。

### 21. 参加秒杀

1. 登录商城。
2. 从首页进入“限时秒杀”。
3. 查看活动开始时间、结束时间、秒杀价、剩余库存和每人限购。
4. 选择目标活动商品和规格。
5. 活动开始后点击“立即抢购”。
6. 选择收货地址并核对数量。
7. 提交秒杀订单并完成支付。
8. 抢购失败时，以页面显示的库存、限购或活动状态结果为准，不要连续重复提交。

### 22. 在复购商城下单

1. 登录商城。
2. 从首页或“我的”进入“复购商城”。
3. 页面提示无资格时，先完成客户设置的首单、会员等级或代理条件。
4. 选择复购商品。
5. 选择规格和数量。
6. 点击“立即复购”。
7. 选择地址，核对复购价格、复购业绩值、数量和运费。
8. 提交复购订单并完成支付。
9. 复购商品不能与普通购物车商品合并结算，需要分别下单。

### 22.1 查看直播广场

1. 在商城首页找到“直播广场”。
2. 点击直播卡片，进入直播详情。
3. 查看直播状态、主播、直播介绍和关联商品。
4. 直播状态为“直播中”时，点击“进入直播”。
5. 系统打开平台配置的直播服务商观看页。
6. 返回直播详情，点击“直播好物”中的商品。
7. 选择规格和数量后，按普通商城流程加入购物车或购买。
8. 直播预告尚未开始时，只查看时间与商品；直播结束后，仅在平台配置回放地址时进入回放。

### 22.2 查看新品速递

1. 在商城首页找到“新品速递”。
2. 点击新品卡片或“全部”。
3. 查看近期首次正式上架的商品。
4. 点击商品进入详情。
5. 选择规格和数量后，按普通商城流程购买。

### 23. 查看和修改个人资料

1. 点击“我的”。
2. 点击头像或“账号设置”。
3. 修改昵称后点击“保存”。
4. 需要设置登录账号时，填写账号和密码并确认。
5. 修改绑定手机号时，分别验证原手机号和新手机号。
6. 保存成功后返回个人中心查看。

### 24. 修改登录密码

1. 进入“我的 → 账号安全”。
2. 点击“修改登录密码”。
3. 输入当前密码。
4. 输入并确认新密码。
5. 按页面要求填写短信验证码。
6. 点击“确认修改”。
7. 使用新密码重新登录。

### 25. 设置或修改支付密码

1. 进入“我的 → 账号安全”。
2. 点击“支付密码”。
3. 点击“获取验证码”，填写绑定手机号收到的验证码。
4. 首次设置时按页面要求验证登录密码。
5. 输入并确认六位数字支付密码。
6. 修改时先输入原支付密码。
7. 点击“确认”。

## 二、团队 H5

### 25A. 使用普通商城账号进入团队 H5

1. 打开客户提供的团队 H5 域名。
2. 点击“登录”，使用普通商城的手机号或登录账号登录。
3. 当前账号尚未建立关系时，在首页输入邀请人的 8 位邀请码。
4. 核对提示，确认该关系只可本人绑定一次。
5. 点击“确认关系”。
6. 关系确认成功后，查看邀请、团队业绩和奖金账户入口。

### 25B. 直接注册团队 H5 账号

1. 打开团队 H5 登录页。
2. 点击“注册新账号”。
3. 输入有效邀请码并确认邀请人。
4. 填写手机号、登录账号、密码和短信验证码。
5. 阅读并勾选协议。
6. 点击“注册并登录”。

### 26. 查看余额和流水

1. 进入“我的 → 我的钱包”。
2. 查看可用余额和支付密码状态。
3. 点击“余额明细”。
4. 按时间查看收入、支出、来源和关联业务编号。
5. 页面加载失败时点击重试，避免把加载失败误认为没有流水。

### 27. 余额转账

1. 进入“我的 → 我的钱包 → 余额转账”。
2. 输入收款会员手机号。
3. 点击“确认收款人”。
4. 核对收款人信息。
5. 输入整数转账金额。
6. 填写转账备注。
7. 输入支付密码。
8. 点击“确认转账”。
9. 结果不明确时先查看余额流水，不要重新发起同一笔转账。

### 28. 申请提现

1. 进入“我的 → 我的钱包”。
2. 点击“申请提现”。
3. 输入提现金额。
4. 选择提现方式。
5. 填写收款账户和收款人姓名。
6. 输入支付密码。
7. 获取并填写短信验证码。
8. 点击“提交申请”。
9. 在提现记录中查看待审核、已通过、已驳回或已打款状态。
10. 如提示达到每日或每月次数、金额上限，停止重复提交并联系运营人员核对当前提现规则。

### 29. 查看团队业绩

1. 登录具有查看权限的账号。
2. 进入“我的 → 团队业绩”。
3. 选择统计周期。
4. 查看个人业绩、团队业绩和来源明细。
5. 页面没有入口时，联系商城管理员确认会员等级和查看权限。

### 30. 使用邀请功能

1. 登录商城。
2. 进入“我的 → 邀请好友”。
3. 查看邀请码、邀请链接和二维码。
4. 点击复制邀请码或邀请链接。
5. 将邀请信息发送给受邀人。
6. 受邀人注册前确认页面显示的邀请人正确。

### 31. 查看公告、协议和经营资质

1. 在首页点击公告进入公告中心。
2. 点击公告标题查看完整内容。
3. 在注册页或首页服务区域打开用户协议、隐私政策和售后规则。
4. 在首页底部点击经营资质入口。
5. 查看商城经营主体、联系方式和已公开的资质资料。

### 32. 退出登录

1. 进入“我的 → 账号设置”。
2. 点击“退出登录”。
3. 在确认窗口点击“确认退出”。

## 三、商城管理后台

### 33. 登录管理后台

1. 打开管理后台登录页。
2. 输入后台账号和密码。
3. 输入图形验证码；看不清时点击刷新。
4. 点击“登录”。
5. 登录后先确认右上角显示的商城名称和当前账号。

### 34. 查看工作台

1. 点击“工作台”。
2. 查看今日订单、销售、会员、待发货、待售后和资金相关数据。
3. 点击待处理事项进入对应订单或售后列表。
4. 需要留档时点击导出。

### 35. 新增商品

1. 进入“商品与订单 → 商品管理”。
2. 点击“新增商品”。
3. 填写商品名称、分类、主图、轮播图和商品介绍。
4. 设置销售价、划线价、库存、预警库存、限购和运费模板；平台自营商品填写参考成本价，商户商品填写结算价。
5. 需要多个规格时，新增规格和规格值，再逐项填写 SKU 价格、库存和状态。
6. 根据客户规则设置业绩值或积分值。
7. 设置普通商城、复购商城等销售渠道。
8. 点击“保存草稿”检查内容。
9. 确认无误后点击“发布”或“上架”。

### 36. 修改商品和库存

1. 进入“商品与订单 → 商品管理”。
2. 按商品名称、分类或状态筛选。
3. 点击商品后的“编辑”。
4. 修改商品资料、规格、价格或库存。
5. 点击“保存”。
6. 需要停止销售时点击“下架”；恢复销售时点击“上架”。

### 37. 管理商品分类

1. 进入“商品与订单 → 分类与规格”。
2. 点击“新增分类”。
3. 填写分类名称、排序和状态，按需上传分类图标。
4. 按需填写备注。
5. 点击“保存分类”。
6. 商品规格在商品管理的“规格、价格与库存”中逐个维护。
7. 删除分类前确认分类没有被商品使用。

### 38. 设置发货与退货地址

1. 进入“商品与订单 → 发货与退货地址”。
2. 点击“新增地址”。
3. 选择地址类型。
4. 填写联系人、手机号、省、市、区/县和详细地址。
5. 需要时设为默认地址。
6. 点击“保存并启用”。

### 39. 查询订单

1. 进入“商品与订单 → 订单管理”。
2. 选择全部、待付款、待发货、已发货、已完成、已关闭或售后状态。
3. 输入订单号、会员账号、手机号、商品名称、物流单号或客服备注关键词。
4. 选择下单时间范围。
5. 点击“查询”。
6. 点击订单查看商品、收款、地址、买家备注、发货和售后信息。
7. 平台账号看到“联合支付”时，点击“查看联合单”，核对本次支付的总金额、子订单金额合计、退款金额和各商户子订单。
8. 商户账号只会看到本商户子订单，不能查看同一联合支付中的其他商户订单。

### 40. 添加客服备注

1. 进入“商品与订单 → 订单管理”。
2. 找到目标订单。
3. 点击订单末尾的“客服备注”。
4. 输入需要后续客服跟进的内容。
5. 点击“保存”。
6. 需要清除时删除全部文字并保存。
7. 返回订单列表，通过备注摘要或备注关键词查找订单。

### 41. 单笔订单发货

1. 在订单管理中筛选“待发货”。
2. 找到目标订单并点击“发货”。
3. 从物流公司下拉框搜索并选择承运商。
4. 填写物流单号。
5. 核对本次发货数量和剩余可发数量。
6. 点击“确认发货”。
7. 返回订单列表确认状态变为已发货或部分发货。
8. 已发货后需要核对运输进度时，点击“查看轨迹”。
9. 系统已接入真实物流服务商时查看运输节点；提示“未配置”时，联系管理员完成服务商接入，不要手工填写虚假轨迹。

### 42. 批量导入物流发货

1. 进入“商品与订单 → 订单管理”。
2. 下载物流导入模板。
3. 按模板填写订单号、物流公司、物流单号和发货数量。
4. 保存文件，不修改模板列名。
5. 点击“批量导入发货”。
6. 上传文件并等待处理结果。
7. 下载或查看失败明细。
8. 修正失败行后仅重新导入失败数据。
9. 商户导入表只能填写本商户订单；其他商户订单或平台已接管履约的订单会逐行跳过并说明原因。

### 43. 导出订单

1. 在订单管理设置状态、关键词和时间范围。
2. 点击“导出订单”。
3. 核对导出范围。
4. 下载并妥善保存文件。

### 44. 处理售后

1. 在订单管理进入“售后处理中”，或进入售后列表。
2. 打开售后申请。
3. 核对订单、申请类型、商品、数量、退款金额、原因和凭证。
4. 同意退货退款时，确认退货地址后点击“同意”。
5. 仅退款且审核通过时，确认退款金额后点击“同意退款”。
6. 不符合规则时填写审核说明并点击“拒绝”。
7. 买家填写退货物流后，核对物流信息和实收商品。
8. 确认收到退货后点击“确认收货并退款”。
9. 商户履约被平台接管或冻结后，只查看订单和填写客服备注，不再操作发货或售后；由平台账号继续处理。

### 45. 后台人工退款

1. 在订单管理找到目标订单。
2. 点击“更多操作 → 后台退款”。
3. 选择按商品数量退款或按金额退款。
4. 选择涉及商品和数量。
5. 金额退款时填写商品退款金额。
6. 填写退款原因。
7. 核对订单已退金额和本次可退上限。
8. 点击“确认退款”。

### 46. 管理商品评价

1. 进入“商品与订单 → 商品评价”。
2. 按商品、星级、状态或关键词筛选。
3. 查看评价内容和对应订单。
4. 违规或不适合公开的评价点击“隐藏”。
5. 需要恢复时点击“恢复显示”。

### 47. 管理会员

1. 进入“会员管理 → 会员全景管理”。
2. 按账号、手机号、昵称、等级或状态筛选。
3. 点击会员查看订单、余额、团队、登录和支付密码状态。
4. 需要时执行启用、停用、修改手机号、重置登录密码或解除锁定。
5. 调整会员等级前核对客户的升级规则和影响范围。
6. 修改资金前进入余额账户页面，不在会员资料中直接改数值。

### 48. 查看团队关系与移线

1. 进入“会员管理 → 团队关系树”。
2. 搜索会员账号、手机号或代理编号。
3. 展开上下级关系查看团队结构。
4. 需要移线时进入“移线记录”。
5. 新建或打开移线申请，核对原上级、目标上级和生效时间。
6. 审核通过前再次确认不会形成循环关系。
7. 审核后在团队关系树复核结果。

### 49. 查看奖金记录和待结算奖金

1. 进入“奖金管理 → 奖金记录”。
2. 按会员、订单、奖金类型、状态和时间筛选。
3. 打开奖金记录查看来源订单和计算结果。
4. 进入“待结算奖金”查看仍处于等待期的记录。
5. 对异常记录先查看订单售后、确认收货时间和计算任务状态。
6. 不要使用人工提前结算替代系统规则。

### 50. 查看业绩统计

1. 进入“业绩统计 → 会员业绩概览”。
2. 选择会员和统计日期。
3. 查看个人、团队及累计业绩。
4. 进入“业绩来源明细”核对贡献会员和订单。
5. 进入“业绩排名”选择周期查看排名。
6. 汇总数据异常时，先核对来源订单，再按授权执行汇总刷新。

### 51. 进行订单奖金与财务追溯

1. 进入“分销审计 → 订单奖金与利润追溯”。
2. 输入订单号或会员信息查询。
3. 打开订单查看实付、退款、奖金、公司留存和资金去向。
4. 进入“会员资金与订单全景”核对单个会员的订单与流水。
5. 进入“财务总览”选择日期范围查看汇总和每日明细。
6. 需要留档时导出当前筛选结果。

### 52. 设置会员端业绩查看权限

1. 进入“分销审计 → 会员端业绩查看权限”。
2. 设置个人业绩、团队业绩和来源明细是否公开。
3. 按客户规则添加允许查看的会员或等级。
4. 点击“保存”。
5. 使用对应会员账号登录商城复核入口和数据范围。

### 53. 查看后台操作日志

1. 进入“分销审计 → 后台操作日志”。
2. 选择操作模块，并按目标类型、业务编号和开始/结束时间筛选。
3. 打开日志查看操作人、请求编号、客户端 IP、浏览器信息和变更摘要。
4. 资金、退款、发货、权限和配置发生争议时，优先按业务编号、操作人和时间范围交叉查询。

### 54. 配置商城视觉与页面

1. 进入“商城设置 → 商城视觉与页面”。
2. 在“首页版型”中选择标准零售版、紧凑商品版、活动信息流版或分类导购版；旧配置未指定时继续使用标准零售版。
3. 选择分类导购版后，再选择 A 双栏目录导航、B 视觉品类橱窗或 C 需求场景导购，并按需开启当前子版型的 3 个模块。切换子版型只改变页面结构，不会修改商品、价格、库存、上下架、购物车或订单。
4. 在“独立页面”中分别控制直播广场、新品速递和品牌文化页。总开关关闭会保护直达页面及现有接口，但不会删除直播、新品精选或品牌正文；首页直播/新品入口仍在“首页模块”中单独控制。
5. 调整轮播、公告、分类、直播、新品、商品、信任/服务等首页模块。关闭后其他模块自动上移，不会保留空白占位；若直播或新品总开关已关闭，对应首页开关会显示禁用原因并保留当前值。
6. 设置商城名称、主题颜色、首页模块和底部导航，并上传商城 Logo、页面图片和轮播图。
7. 购物车、账号和其他系统必需/合规能力会显示为锁定状态，普通运营人员不能关闭；如旧底部导航缺少购物车或账号入口，工作台会自动补回。
8. 使用右侧手机预览检查当前主版型、分类导购子版型和模块开关效果，再点击“保存发布”。需要撤销已发布装修时，从现有历史记录恢复后重新发布。
9. 打开公开商城分类页并切换分类、场景、货架和加入购物车操作，确认真实商品信息无误；关键分类或商品内容缺失时页面会显示安全提示，不应出现空白页。
10. 活动信息流版只有关联真实秒杀活动的商品显示倒计时和活动价格；普通商品不显示虚假倒计时。

### 55. 配置商城资料与客服

1. 进入“商城设置 → 商城资料与客服”。
2. 填写商城名称、客服电话、客服邮箱和客服时间。
3. 填写经营主体、统一社会信用代码、经营地址等资料。
4. 上传营业执照或经营资质图片。
5. 按需填写 App 下载和客户品牌资料。
6. 点击“保存”。
7. 在商城首页、登录页、经营资质页和 App 下载页逐项复核。

### 56. 配置秒杀与复购模式

1. 进入“商城设置 → 秒杀与复购模式”。
2. 按客户需求开启或关闭秒杀入口。
3. 按客户需求开启或关闭复购商城。
4. 设置复购准入条件。
5. 为秒杀和复购分别选择奖金处理方式。
6. 客户定制奖金规则尚未验收时，不要启用对应下单。
7. 点击“保存”。

### 57. 创建秒杀活动

1. 先在商品管理中准备已上架商品和可售库存。
2. 进入“商城设置 → 秒杀活动”。
3. 点击“新增活动”。
4. 填写活动名称。
5. 选择参与秒杀的单个商品和规格。
6. 设置秒杀价、秒杀业绩值、秒杀库存和每人限购。
7. 设置开始时间和结束时间。
8. 保存后检查活动状态。
9. 确认库存、价格和时间无误后启用活动。
10. 活动开始前使用测试会员账号检查入口和结算页面。

### 58. 配置复购商品

1. 进入“商品与订单 → 商品管理”。
2. 编辑目标商品。
3. 开启复购渠道。
4. 设置复购价、复购业绩值、复购限购和规格覆盖值。
5. 保存并发布商品。
6. 进入“商城设置 → 秒杀与复购模式”确认复购商城和准入条件已启用。
7. 使用符合条件的会员账号登录复购商城检查商品。

### 58.1 开通或收回主播权限

1. 先让厂家主播、平台讲解员或工厂负责人注册普通商城账号。
2. 进入“商品与库存 → 直播运营中心”。
3. 打开“主播账号”页签。
4. 点击“授权主播”。
5. 输入主播的商城登录账号。
6. 填写对外展示名称、直播类型和所属单位。
7. 点击“确认授权”。
8. 授权成功后，主播可以随时进入主播工作台开播，不需要每场重新审核。
9. 需要临时限制时，将主播状态改为“暂停开播”；已有直播会停止，但账号资料保留。
10. 需要永久收回时，将主播状态改为“收回权限”；已有直播会停止，之后不能再次开播。
11. 恢复权限时，将状态改回“可开播”。

### 58.2 创建直播间

1. 先在“商品与库存 → 商品管理”准备已审核并上架的普通商城商品。
2. 进入“商品与库存 → 直播运营中心”。
3. 点击“新建直播间”。
4. 选择“厂家商品直播”“平台讲解直播”或“工厂实景直播”。
5. 选择已授权主播，填写直播标题、介绍、计划时间和封面。
6. 选择“腾讯云直播”或“外部固定视频源”。
7. 使用工厂监控、已有摄像设备或第三方直播地址时，选择“外部固定视频源”并填写公开 HTTPS 观看地址。
8. 从商品列表中选择直播要展示的商品，单场最多选择 20 个。
9. 按需要开启评论和分享。
10. 保存为“预告”，在公开商城检查封面、主播、时间和关联商品。
11. 直播状态不能由管理员手工伪造为“直播中”，必须由已授权主播实际开始直播。

### 58.3 主播开始和结束直播

1. 主播使用已获授权的商城账号登录。
2. 打开“主播工作台”。
3. 选择平台分配给自己的直播间。
4. 点击“开始直播”。
5. 使用腾讯云直播时，复制本次生成的短时推流地址，粘贴到平台指定的主播工具并开始推流。
6. 使用外部固定视频源时，确认厂家摄像设备或已有直播源已正常播放。
7. 打开直播观看页，确认画面、声音、评论、观看人数和商品入口正常。
8. 直播结束时，先停止主播工具或厂家视频源，再在主播工作台点击“结束直播”。
9. 不要把短时推流地址转发给其他人；地址失效后重新点击开始直播获取。

### 58.4 观看、互动和直播运营

1. 用户从首页“直播广场”进入直播间。
2. 点击播放画面开始观看。
3. 在评论区输入内容并发送；未登录时先完成登录。
4. 点击“分享”发送直播链接。
5. 点击直播商品进入详情页，再按正常流程加入购物车或下单。
6. 运营人员进入“直播运营中心”，查看观看人数、平均停留、分享、评论、商品点击、归因订单、成交额和转化率。
7. 对违规评论执行隐藏。
8. 发现违规、画面异常或主播失联时，点击“强制停播”，填写原因并完成二次验证。
9. 需要临时关闭整个直播业务时，进入“商城设置 → 商城视觉与页面 → 首页版型与直播”关闭直播广场；重新开放时无需重建直播间。

### 58.2 管理新品速递

1. 在商品管理中完成商品资料和审核。
2. 商品第一次正式上架后，系统自动记录首次上架时间。
3. 符合新品展示天数的商品自动进入“新品速递”，不需要重复勾选。
4. 商品后续编辑、调价或重新保存不会重新计算首次上架时间。
5. 需要调整新品展示周期时，由维护人员修改部署配置后重新发布。
6. 进入“商城设置 → 商城视觉与页面”，可调整“直播广场 + 新品速递”模块顺序或关闭该模块。

### 59. 管理商城公告

1. 进入“商城设置 → 商城公告”。
2. 点击“新增公告”。
3. 填写标题、公告类型、正文、排序和展示状态。
4. 点击“保存”。
5. 需要暂停展示时点击“隐藏”。
6. 删除前确认公告不再需要，并在确认窗口再次确认。
7. 打开商城首页和公告中心复核。

### 60. 配置协议、规则和售后期限

1. 进入“商城设置 → 协议与规则”。
2. 完善用户服务协议、隐私政策、售后规则和相关说明。
3. 进入“交易与售后”。
4. 选择售后期限从“签收后”或“下单后”起算。
5. 设置售后入口有效天数；设置为 0 天时，会员自助申请入口关闭。
6. 点击“保存”。
7. 使用测试订单验证会员端入口是否符合客户规则。

### 61. 配置奖金与钱包规则

1. 进入“商城设置 → 奖金与钱包规则”。
2. 选择客户使用的奖金规则版本。
3. 设置商品业绩值、奖金展示和钱包相关参数。
4. 使用奖金模拟功能输入测试条件。
5. 核对模拟结果后保存。
6. 正式启用前用完整测试订单验证计算、售后冲销和结算。

### 62. 配置 ERP 订单对接

1. 进入“商城设置 → ERP订单对接”。
2. 点击“新增对接”。
3. 选择或填写客户实际 ERP 的对接类型和必要资料。
4. 设置启用状态。
5. 保存后先使用测试订单验证推送、回执和发货回传。
6. 进入任务列表查看成功和失败记录。
7. 修复失败原因后点击“重试”。
8. 客户未确定 ERP 时保持关闭，不填写虚假连接信息。

### 63. 审核提现和确认打款

1. 进入“提现管理 → 提现审核”。
2. 打开待审核申请。
3. 核对会员、余额、提现金额、手续费和收款信息。
4. 符合条件时点击“审核通过”；不符合时填写原因并点击“驳回”。
5. 实际完成打款后进入提现记录。
6. 填写打款流水号并点击“确认打款”。

### 64. 调整会员余额

1. 进入“账户管理 → 会员余额账户”。
2. 搜索目标会员。
3. 打开账户详情并核对当前余额和近期流水。
4. 点击“增加余额”或“扣减余额”。
5. 输入金额、业务原因和管理员密码。
6. 再次核对会员和金额。
7. 点击“确认”。
8. 在余额流水中按业务编号复核结果。

### 65. 导入外部团队或历史订单

1. 进入“数据迁移”。
2. 选择“外部团队平移”或“历史订单导入”。
3. 下载当前模板。
4. 按模板填写数据，不修改列名和数据格式；文件使用 XLSX、XLS、CSV 或 TXT 格式。
5. 先使用少量测试数据导入。
6. 单个常规导入文件不超过 5000 行；团队平移单批不超过 1000 行，超过时拆分批次。
7. 确认当前没有其他导入任务后上传文件并记录批次号；同一商城一次只运行一个导入任务。
8. 打开导入结果查看成功、失败和原因。
9. 修正失败数据后按新批次重新导入。
10. 正式批量导入前先完成数据库备份。

### 66. 管理后台账号和权限

1. 进入“系统与权限 → 后台账号与权限”。
2. 点击“新增账号”。
3. 填写账号、姓名和初始密码。
4. 只勾选岗位实际需要的权限。
5. 点击“保存”。
6. 创建商户工作台账号时，在“账号归属”选择对应商户；系统自动限定为基础查看、商品管理和本商户货款权限。
7. 商品审核人员勾选“商户商品审核”权限，不要把审核账号绑定到商户。
8. 修改权限、状态或密码时，先打开目标账号再操作。
9. 账号锁定时点击“解除锁定”。
10. 使用该账号重新登录，确认菜单和操作范围正确。

### 66A. 新增和维护商户

1. 进入“商品与订单 → 商户管理”。
2. 点击“新增商户”。
3. 填写商户名称、经营主体、统一社会信用代码、联系人和联系电话；商户编号可留空自动生成。
4. 填写收款户名、开户银行、银行账号，以及开票抬头和纳税人识别号。
5. 核对合同后把合同状态设置为“已签署”；未签署或资料不完整的商户不能提现。
6. 设置“默认结算等待天数”，允许 0～365 天；0 天表示售后窗口结束后即可进入可提现，高风险商户可设置更长时间。
7. 设置“应缴保证金”；0 表示不要求保证金，大于0时未缴足不能提交商品审核或提现。
8. 点击“保存”。修改默认结算等待天数后，依赖默认值的商品会自动下架并重新审核；已单独设置等待期的商品不受影响。
9. 需要暂停合作时，在商户列表点击“停用”；该商户商品自动下架，前端和新订单立即停止销售。
10. 历史订单、货款、提现和审核记录仍保留；重新启用商户后，商品仍需按正常审核流程上架。
11. 商户准备退出时，点击“业务控制”，先选择“清退中”；系统会暂停新销售并冻结新提现，但保留历史履约能力。
12. 点击“退出检查”，逐项处理仍在售商品、未完成订单、开放售后、待结算货款、处理中提现及账户余额。
13. 只有退出检查全部通过后，才能关闭账号、经营、履约、提现和结算能力，并把退出状态改为“已退出”；系统会再次检查，不通过时不会保存。

### 66B. 将商品绑定商户并选择销售区

1. 进入“商品与订单 → 商品管理”。
2. 新增或编辑目标商品。
3. 商户工作台账号会自动绑定本商户；平台账号可在“销售方”选择商户，不选择表示平台自营。
4. 设置销售价、规格、结算价和库存。结算价是平台应付给商户的单件货款。
5. 在“结算等待”选择“跟随商户默认”或“单品单独设置”；高风险商品可单独设置 30 天，允许范围为 0～365 天。
6. 保存后商品进入下架草稿，在商品列表点击“提交审核”。
7. 已上架商品需要改销售价、结算价或结算等待天数时，先点击“下架”，再编辑并重新提交审核。
8. 在销售渠道中选择“普通商城”“复购区”或“报单区”。
9. 选择团队奖金方式：“继承商城规则”“不发团队奖”“标准团队奖”或“客户定制”。
10. 标准团队奖商品只能进入复购区或报单区，不要同时开启普通商城。
11. “客户定制”在客户规则开发并验收前不能用于正式下单。
12. 审核通过后再用测试账号核对前端商品和下单结果；新订单使用最新审核通过的结算价和等待天数，旧订单仍按原下单快照结算。

### 66B-1. 审核商户商品

1. 进入“商品与库存 → 商户商品审核”。
2. 在“待审核”列表查看商户、商品、销售价、结算价和SKU数量。
3. 点击“查看详情”，逐项核对各SKU销售价与结算价。
4. 如系统提示结算价高于销售价，先驳回并要求商户修正，不能直接通过。
5. 确认无误后点击“审核”→“通过并上架”；商品立即在前端显示。
6. 信息不完整时选择“驳回修改”，填写明确原因；商品继续保持下架。
7. 商户修改后重新提交，审核页会生成新的版本记录；已处理的旧版本不能重复审核。

### 66C. 查看商户货款

1. 进入“财务与审计 → 商户货款”。
2. 打开“货款账户”，查看待结算、可提现、提现冻结、保证金冻结、退款欠款和累计已打款。
3. 打开“订单货款明细”，按订单核对结算单价、数量、应结货款、退款冲回、结算等待天数和预计可结算时间。
4. 核对公式“订单结算单价 × 有效数量＝应结货款”。
5. 预计可结算时间按“确认收货时间、售后截止时间两者较晚者，再加商品结算等待天数”计算。
6. 发现售后或退款时，先核对退款数量和已冲回金额，再处理提现。

### 66C-1. 冻结或解冻商户保证金

1. 进入“财务与审计 → 商户货款”。
2. 在“货款账户”找到目标商户。
3. 已有可提现货款时点击“转入保证金”，填写金额和真实原因；系统从可提现余额转入保证金。
4. 商户线下另行缴纳时点击“登记线下到账”，核对银行到账后填写金额和真实原因；该操作只允许平台财务执行。
5. 打开“保证金流水”，核对操作类型、金额、操作后保证金、原因和操作人。
6. 需要解除时回到“货款账户”点击“解冻”。
7. 填写金额和原因并确认；系统优先抵扣商户退款欠款，剩余金额返回可提现余额。
8. 同一笔操作不要重复点击；页面重试会使用操作请求号防止重复入账、冻结或解冻。

### 66C-2. 商户自行查看货款和申请提现

1. 使用已绑定商户的工作台账号登录后台。
2. 登录后系统直接进入“商户货款工作台”，无需进入平台经营看板。
3. 查看本商户货款账户、订单货款明细、保证金流水和提现进度。
4. 确认合同已签署、收款资料完整且保证金已缴足。
5. 点击“申请提现”，填写不超过当前可提现余额的金额并提交；网络重试不会重复冻结同一笔金额。
6. 财务尚未开始付款且状态为“待审核”或“待收发票”时，可点击“撤回”并填写原因；撤回后冻结金额先抵欠款，剩余返回可提现。
7. 等待平台财务审核发票和打款；申请记录固定保存申请当时的主体及银行账户，后续修改商户资料不会改变旧申请。
8. 商户账号不能查看其他商户，也不能登记或解冻保证金、审核发票、确认打款；只有具备本商户资金管理权限的账号可以申请或撤回提现。

### 66D. 处理商户提现、发票和打款

1. 进入“财务与审计 → 商户货款”。
2. 点击“代商户申请提现”。
3. 选择商户并填写申请金额，提交后对应余额进入冻结。
4. 在“提现、发票与打款”找到申请，点击“发票/审核”。
5. 填写应开票金额、已收票金额和发票状态。
6. 不需要调整时将调整金额保持为 0；需要少打款时填写负数调整金额，并填写真实调整原因。
7. 不要把通用调整金额固定写成“税费”；税务口径由财务根据合同、发票和当地要求判断。
8. 负数调整会减少本次商户应付，不会退回可提现余额；冻结后产生退款欠款时，调整金额必须先覆盖欠款。
9. 发票条件满足后点击“开始付款”；系统进入“付款处理中”，冻结资金保持不变。
10. 银行实际付款成功后点击“确认到账”，填写实际打款金额、银行流水号和凭证地址；实际金额必须等于申请金额加调整金额。
11. 银行退回或账户异常时点击“付款失败”并填写原因；金额继续冻结，可修正后重新“开始付款”，也可驳回结束。
12. 发现可疑申请时点击“风控冻结”并填写原因；核查完成后点击“解除冻结”，流程恢复到冻结前状态。
13. 已打款且银行凭证、发票及审批资料齐全后点击“归档完成”。
14. 不同意申请时点击“驳回”，填写原因；系统先用解冻金额抵扣已产生欠款，再把剩余金额退回可提现余额。
15. 已完成、已驳回或已撤回的申请不能重复处理；发票仍为“待收发票”时不能开始付款。

### 66D-1. 核对商户资金账本

1. 进入“财务与审计 → 商户货款”。
2. 点击“账本对账”。
3. 逐个商户核对待结算、可提现、提现冻结、保证金、欠款和累计已打款。
4. 显示“账实一致”时，表示账户当前余额与该商户末笔总账余额一致。
5. 显示“存在差异”时，暂停该商户提现和人工调整，打开“资金总账”查找缺失或异常流水。
6. 不要直接修改余额消除差异；确认业务来源并由维护人员修复流水或执行经过审批的调账。

## 四、交付前操作验收

### 67. 客户交付前检查

1. 进入“商城设置 → 商城资料与客服”，查看“客户交付预检”。
2. 逐项处理“交付必备”的未通过项目；“客户可选”项目按客户是否采购决定。
3. 使用客户资料替换商城名称、Logo、联系方式和经营资质。
4. 检查首页轮播、分类、商品、价格、库存、运费、公告和协议。
5. 分别使用新会员、普通会员、复购会员和后台角色账号登录。
6. 完成普通下单、支付、发货、确认收货、评价和带图片凭证的售后流程。
7. 客户启用秒杀时完成活动创建、并发抢购、支付、取消和库存回补验证。
8. 客户启用复购时完成资格、独立结算、奖金方式和退款验证。
9. 客户启用钱包时完成余额支付、转账、提现、审核和流水核对。
10. 客户启用团队奖金时完成邀请、关系、业绩、奖金计算、售后冲销和等待期结算验证。
11. 客户启用 ERP 或物流轨迹时，使用真实测试单完成双向联调。
12. 清理或隐藏全部测试商品、测试分类、测试公告、无效地址和测试下载内容。
13. 使用手机、电脑和客户计划交付的 App 分别验收。
14. 预检必备项全部通过且完成备份后，再执行正式发布。

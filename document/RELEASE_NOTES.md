## 当前仍未完成

以下内容不能标记为“已完成”，后续版本要继续从这里接着做：

1. 微信支付、支付宝支付尚未完成正式商户环境的端到端接入和真实资金验证；不能按“已上线支付”对外说明。
2. ERP 正式接口尚未对接；目前只有订单表格导出、发货表下载、物流导入和分批发货能力。
3. 线上运营主体、统一社会信用代码、客服电话、联系地址、第三方支付及短信服务商等协议内容尚未配置；线上协议页目前显示“该内容暂未配置，请联系客服”。
4. 数据库仍有2个隔离的内部系统账户。用户要求最终彻底删除这些账户；当前奖金剩余金额和产品成本归集逻辑仍依赖它们，必须先改完归集、退款冲回和账务关联并完成回归测试，不能直接删表记录。
5. Android 安装包本次没有重新生成；iOS 包也未构建。网页版本已更新，但 APP 是否需要重新安装取决于最终采用远程网页壳还是内置前端资源方案。
6. 服务器仍提示有系统更新和“需要重启”；应安排维护窗口安装安全更新并重启验证，不能在商城正常营业时直接操作。

## 已确认的长期安全基线

- 全站使用 HTTPS，HTTP 自动跳转 HTTPS，HSTS 和 CSP 已启用。
- MySQL 与 Redis 只监听本机地址；后端健康接口不对公网开放。
- 密码、交易密码、验证码等敏感请求字段除 TLS 外，还使用一次性 RSA-OAEP + AES-256-GCM 应用层加密；服务器拒绝未加密敏感载荷。
- 密码只保存不可逆哈希，不在报告、日志或接口响应中输出原文。
- 管理后台会话失效、登录锁定、敏感操作再认证、余额流水和操作日志均已建立。

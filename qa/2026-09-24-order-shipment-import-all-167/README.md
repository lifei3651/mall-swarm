# 1.0.167 订单管理“全部”页的物流批量导入入口

用户明确选择“导入物流并发货”，要求在订单管理“全部”页使用。该入口作用于已有商城订单的物流和发货，不是“数据迁移→历史订单导入”，不会新建商城交易订单或历史业绩记录。

## 修改与边界

- 后台“全部”和“待发货”同时展示下载预填发货表、下载空白导入模板、导入物流并发货、默认物流商配置；其余状态筛选不展示。批量操作在窄宽度可换行。
- 页面与确认框说明只处理现有且可发货的订单；不可发货行会跳过并返回原因。保留服务端原有租户、商户履约权限、售后进行中、订单状态、重复运单及剩余可发数量校验。部分发货后仍有剩余数量的已发货订单，仍按原有服务端规则处理。
- 历史订单导入入口仍在“数据迁移”，没有改动其业绩/奖金流程。

- 小程序 `npm run check`：通过，仅验证根版本与微信工程结构；后端和 H5 产品代码未改，完整统一候选 C/T 尚未重跑。

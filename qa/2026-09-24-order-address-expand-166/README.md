## 缺陷与修复

- 小程序原有展开逻辑只在完整地址与遮盖地址之间切换；姓名和电话始终遮盖，地址文本仍被 `white-space: nowrap`、`text-overflow: ellipsis` 截断。事件使用长订单 ID 作为 `dataset` 值，存在整数精度转换导致定位失败的风险。
- 现在收起态保留姓名/电话/地址脱敏，展开态显示完整姓名、电话和可多行换行的地址；复制读取完整信息。展开操作按当前页面行序号定位，刷新后保留该订单的展开状态。
- 公开商城 H5 的同款收货信息展开同步去除单行截断、显示完整姓名电话；售后入口的地址展开同步显示收件信息。
- 同类扫描：小程序与 H5 中 `maskedRecipient`、`maskedAddress`、`addressExpanded` 和“展开后查看完整地址”的入口已核对；没有把默认收起态改成公开明文展示。

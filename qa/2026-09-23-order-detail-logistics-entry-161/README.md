# 1.0.161 订单详情物流入口精简（未发布）

## 反馈与修复边界

- 用户在 1.0.158 体验版真机截图中指出：详情物流卡重复出现“物流配送中”、商品卡“查看物流”和承运商名称，商品操作又有“还想买 / 再买一单”，导致文案和按钮过多。原截图只保留在对话附件，不入库。
- 小程序订单详情删除重复状态和商品卡物流按钮；有运单号时，每个包裹的承运商名称成为唯一物流查询入口，复用原 `openWeChatTracking` 的订单、包裹、微信凭证与官方插件链路。多包裹逐一带包裹 ID，单包裹不显示“包裹 1”。运单号、发货时间和复制保留；不再为已移除的站内轨迹展示自动发送隐形查询。
- 小程序及公开商城 H5 的商品卡均移除“还想买 / 再买一单”。H5 物流入口也移到承运商名称，继续使用网页查询链接；H5 不具备小程序物流插件，不能记成微信插件验收。
- 订单列表、售后、评价、确认收货、后端物流/发货同步及微信平台配置未修改。

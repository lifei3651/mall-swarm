# 微信小程序公开商城

这是商城基座的独立原生微信小程序前端，不是把 H5 页面套进小程序。当前提供商品浏览、分类、商品详情、购物车、微信快捷登录/首次手机号注册、个人中心和订单列表基础能力。

## 基座与客户项目的边界

- 基座统一维护：`wx.login` 登录流程、手机号授权注册、邀请参数携带、商城账号匹配、登录态、公开商品与订单读取、安全限流和隐私同意留痕。
- 每个客户单独配置：小程序 AppID、AppSecret、合法域名、隐私声明版本、主体认证、类目、备案、审核与发布。
- 每个客户单独开发或联调：微信支付商户号、支付与退款、订阅消息模板、客户特有页面及奖金制度。
- 小程序公开页面不得展示奖金制度、团队层级、余额互转或招商收益宣传。

## 客户项目启用步骤

1. 在微信公众平台注册客户自己的小程序并取得 AppID。
2. 将 `project.config.json` 的测试 AppID 替换为客户 AppID；本机调试设置放在不提交的 `project.private.config.json`。
3. 把 `config/runtime.js` 的 API 地址替换为客户 HTTPS 域名，并在微信公众平台加入 request 合法域名。
4. 服务器私有环境配置客户 AppID、AppSecret、隐私版本和功能开关；AppSecret 只能保存在服务器。
5. 小程序的 `PRIVACY_CONSENT_VERSION` 必须与服务器一致，否则登录会安全停止。
6. 使用微信开发者工具和至少一台微信真机完成授权同意、拒绝、老用户登录、新用户手机号注册、扫码邀请、弱网和退出重登验收。

## 本地检查

```bash
npm test
npm run build
```

当前结算入口会明确提示尚未配置客户微信支付，不会创建无法支付的订单。取得客户支付资料并完成真实小额支付、回调、退款与重复通知验收后，才能开放结算。

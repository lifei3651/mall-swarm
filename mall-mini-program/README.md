# 微信小程序公开商城

这是商城基座的独立原生微信小程序前端，不是把 H5 页面套进小程序。当前提供商品浏览、分类、商品详情、购物车、微信快捷登录/首次手机号注册、收货地址、结算、微信支付、订单列表，以及微信购物订单按商户单号直达订单详情的能力。

## 基座与客户项目的边界

- 基座统一维护：`wx.login` 登录流程、手机号授权注册、邀请参数携带、商城账号匹配、登录态、商品/购物车/地址/订单、微信支付与退款程序、安全限流和隐私同意留痕。
- 当前灵启商城基座体验版默认连接`https://lingqimall.com/api`；客户派生工具仍会把该地址重置为不可发布的安全占位域名，避免误连基座生产环境。
- 每个客户单独配置：小程序 AppID、AppSecret、合法域名、隐私声明版本、主体认证、类目、备案、审核与发布。
- 每个客户单独配置与联调：微信支付商户号、证书/公钥、API v3密钥、回调及真实资金验收；订阅消息模板、客户特有页面及奖金制度按客户需求处理。
- 小程序公开页面不得展示奖金制度、团队层级、余额互转或招商收益宣传。

## 客户项目启用步骤

1. 在微信公众平台注册客户自己的小程序并取得 AppID。
2. 将 `project.config.json` 的测试 AppID 替换为客户 AppID；本机调试设置放在不提交的 `project.private.config.json`。
3. 把 `config/runtime.js` 的 API 地址替换为客户 HTTPS 域名，并在微信公众平台加入 request 合法域名。
4. 服务器私有环境配置客户 AppID、AppSecret、隐私版本和功能开关；AppSecret 只能保存在服务器。
5. 小程序的 `PRIVACY_CONSENT_VERSION` 必须与服务器一致，否则登录会安全停止。
6. 启用微信支付前绑定客户AppID与商户号，配置客户商户API私钥、微信支付公钥、API v3密钥及支付/退款HTTPS回调，完成小程序支付权限和发货信息管理要求。
7. 在微信公众平台“订单管理”签署订单中心授权协议，开启“订单信息录入”，将订单详情路径配置为`pages/order-detail/index?orderNo=${商品订单号}`；占位符必须原样保留，由微信用JSAPI下单的`out_trade_no`替换。
8. 使用微信开发者工具和至少一台微信真机完成授权同意、拒绝、老用户登录、新用户手机号注册、扫码邀请、弱网、退出重登、真实小额支付、微信购物订单找回与详情回跳、取消支付、查单、超时关单、重复通知、发货同步和售后退款验收。

“实物交易类小程序跳转规范”限制的是广告、其他小程序互跳、半屏小程序、插件支付和超过默认额度的scheme码，不代替订单管理接入。客户不使用这些营销跳转时可保留限制；确需恢复时，应按实际零售/B2B业务和微信当期规则提交品牌资质或选择相应闭环方案，不得为了开通跳转擅自改变客户交易架构。

## 本地检查

```bash
npm test
npm run build
```

微信支付程序已经接入，但基座开关保持关闭；结算入口会在创建订单前提示客户尚未配置支付。取得客户资料并完成真实小额支付、回调、关单、退款与重复通知验收后，才能开启`WECHAT_PAY_ENABLED`。本能力不包含微信支付分账，也不会在公开小程序展示客户奖金制度。
# 后台装修联动（1.0.122 起）

小程序直接读取现有商城 `/shop/home` 的装修配置，不需要另一份后台设置。

- 首页支持轮播、公告、分类、直播、新品、服务条、商品的开关和顺序；首页分类、直播、新品及服务条同时遵守对应总开关。
- 支持四种原生首页布局、三种分类导购模板及其九个模块开关，布局是小程序原生适配，不是把H5页面直接嵌入。
- 读取九项详细配色和主题圆角；底部导航名称、分类显隐、订单入口可配置。首页、购物车和我的始终保留，与后台/H5规则一致。
- 返回首页或下拉重新读取装修；其他页面配置短缓存10秒后重取。网络失败时保留上次页面，不写回或覆盖后台设置。
- 品牌文化、新品和直播内容页使用既有公开接口。外部URL轮播不直接打开网页；直播仅支持HTTPS MP4/HLS原生播放，实际视频域名、真机兼容性及互动能力须单独验收。本轮没有实现网页桥接或完整直播互动。

必须先上传、审核并发布含本功能的新版小程序，旧的在审/线上包不会自动获得代码修复。之后已支持的装修项改配置即可刷新生效，新增组件或新功能仍需要更新小程序代码。

## 1.0.124 交易与通知补齐

- 结算支持非默认地址选择；报价/短信风控未成功，或商品/地址已变化尚未重算时不允许创建订单。限时活动从专用活动接口报价/下单，不能失败后改成普通订单。
- 售后从订单详情发起：申请、可选凭证、取消、退货物流填写/修改及换货确认。退款金额与资格由后端裁定，不由客户端定价。可选凭证使用既有媒体接口，需配置客户 `uploadFile` 合法域名、微信隐私指引及对应图片用途；拒绝图片授权仍能填写无图片申请。
- 个人中心新增账号与安全；首次独立账号设置与密码修改沿用后端规则，凭据修改后清会话重登。敏感字段通过共用请求层加密，依赖微信安全随机能力；不可用时停止发送，不降级为未加密正文。算法、依赖来源和可复现构建见 `vendor/payload-crypto/SOURCE.json` 与生成脚本。
- 商品支持完整分页，外部搜索清除旧分类；公告与政策页读取商城后台实际配置。运营主体、客服、资质或政策缺失需要客户补全，不以默认文案代替真实资料。
- 四类订阅提醒以最多三个模板一组，由用户逐组点击；授权结果保存失败可重试，不能自动连续弹窗。后台“消息运营”显示各模板就绪状态及脱敏发货同步台账；仅授权平台管理员可对永久失败任务重新排队，不重放资金业务。
- 微信实付订单部分发货后退款导致剩余应发数量已覆盖时重新同步履约，包含零元赠品退款。历史已成功但曾遗漏退款后更新的任务不自动重传，需先只读核对再确定恢复范围。

本版同时包含小程序、共用后端和管理后台改动，需配套发布；本地验证不代表微信审核、真机资金流程或正式上线已经完成。不得仅上传小程序就将后台新台账/退款补同步认定为已上线。
